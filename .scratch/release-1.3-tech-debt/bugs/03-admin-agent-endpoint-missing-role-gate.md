# Б-3 — Эндпойнт `/api/v1/admin/agent/run` без ролевого гейта (путь admin, доступ у любого)

Type: bug
Status: open
Найдено при: прожарка releases-1.5-1.9-wow-demo (разбор механики «ночной агент»)
Регрессия в: не регрессия — дефект с момента появления эндпойнта
(`release-0.7-ai-import` / `agent`-пакет, `AgentController`).

## Симптом

Путь эндпойнта — `/api/v1/admin/agent/run`, но вызвать его может **любой
аутентифицированный пользователь**, включая демо-гостя. Ущерб ограничен (эндпойнт гоняет
агента только для текущего пользователя, а не для чужих данных), но это:
1. расход LLM-квоты по запросу любого гостя (`wolf.llm.enabled=true` стенда),
2. вводящий в заблуждение путь `admin` без фактической админ-проверки,
3. несоответствие остальным админ-эндпойнтам проекта.

## Доказательство расхождения

- `AgentController.java` — `@RequestMapping("/api/v1/admin/agent")`, `@PostMapping("/run")`,
  **без `@PreAuthorize`** (единственные `@PreAuthorize("hasRole('ADMIN')")` в проекте — на
  `AdminController.java:38`, `InviteController.java:41`, `InstanceController.java:53`).
- `SecurityConfig.java:35-47` — в цепочке **нет matcher'а на `/api/v1/admin/**`**:
  только `.anyRequest().authenticated()`. То есть admin-префикс ничем не защищён сверх
  обычной аутентификации.
- Сравнение с `AdminController`: `@RequestMapping("/api/v1/admin/users")` +
  `@PreAuthorize("hasRole('ADMIN')")` — у AgentController класс-уровневый гейт отсутствует.

## Затрагиваемый код

- `api/src/main/java/ru/wolf/api/agent/AgentController.java`
- `api/src/main/java/ru/wolf/api/auth/SecurityConfig.java` (добавить matcher
  `/api/v1/admin/**` → `hasRole('ADMIN')` либо `@PreAuthorize` на контроллер)

## Ожидаемое поведение (DoD)

- `GET/POST` на любой `/api/v1/admin/**` без роли `ADMIN` → `403`.
- Демо-гость (`DEMO`) и обычный пользователь (`REGULAR`, роль `USER`) не могут запустить
  агента по admin-пути.
- Существующие вызовы агента (кнопка админа в UI, если есть) продолжают работать.

## Примечание (связь с wow-механикой 1.7)

Прожарка 1.5–1.9 показала: для кнопки «Смоделировать ночь» у демо-гостя нужен **отдельный
разрешённый путь** ручного прогона агента для текущего пользователя (сейчас это делает
этот эндпойнт). Закрытие бага не должно оставить UI без этого пути — релиз 1.7 (Ф2)
вводит легальный эндпойнт вне admin-префикса. В объём 1.3 входит только закрытие дыры.
