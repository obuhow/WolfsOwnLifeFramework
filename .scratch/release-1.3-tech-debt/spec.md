## Problem Statement

Релиз 1.3 — «укладка» техдолга: закрываем дефекты, накопленные к 1.2. Первый и порождающий
пункт — **Б-1**: при отправке запроса встроенному агенту (плавающая чат-панель «＋»,
`ImportChatPanel.vue`) на вставку Дел в расписание ничего не появляется в расписании.

«Встроенный агент» здесь = **канал чат-панели импорта** (релиз 0.7, тикет 02): кнопка «＋»
в правом нижнем углу (`App.vue`, `import-fab`) открывает панель, пользователь пишет свободный
текст → `POST /api/v1/import/parse` (LLM-разбор в кандидатов Дело/Проект/Рутина/Повторение) →
предпросмотр → `POST /api/v1/import/confirm` создаёт сущности через
`ImportConfirmService`. Материализацию расписания делает ветка `RECURRENCE` (через
`RecurrenceService`) и явный `startAt` у ветки `DELO` (параллельный слот).

Разбор показал: happy-path работает и покрыт тестами, но **повторяющиеся дела молча
теряются** на стыке разбора и подтверждения — Дело создаётся, а Записи времени нет, без
ошибки. Подробности и доказательства — `bugs/01-import-chat-recurrence-silent-drop.md`.

## Обнаруженные баги (живой сайт, релиз 1.3)

Живут в `bugs/` со сквозной нумерацией релиза.

- **Б-1** — чат-панель «＋»: повторяющееся дело не попадает в расписание (тихий no-op на
  стыке `import/parse` → `import/confirm`), а часть ошибок разбора глотается без сообщения.
  См. `bugs/01-import-chat-recurrence-silent-drop.md`.
- **Б-2** — полоса заполнения проекта: на дневной странице Ежедневника (`TodayView.vue`)
  её нет вообще (есть только на вкладке «Неделя»), и оба списка строятся от Дел, поэтому
  Проект с недельной нормой без привязанных Дел не показывается. Недоделанный вертикальный
  срез resolved-тикета 06 релиза 1.1. См.
  `bugs/02-daily-project-fill-bar-not-on-today-and-no-norm-only-projects.md`.
- **Б-3** — эндпойнт `/api/v1/admin/agent/run` без ролевого гейта: путь admin, доступ у
  любого аутентифицированного (найдено прожаркой 1.5–1.9, `AgentController` без
  `@PreAuthorize`, в `SecurityConfig` нет matcher'а `/api/v1/admin/**`). См.
  `bugs/03-admin-agent-endpoint-missing-role-gate.md`.

## Итог релиза

Объём закрыт: **4 тикета, 3 бага** (Б-1, Б-2, Б-3 — все `resolved`).

Мерж `506c31c` |
| 02 | Б-2 | Полоса заполнения на дневной странице + проекты с недельной нормой без Дел. Мерж `dfa90d0` + ревью-правка `b351408` |
| 03 | Б-3 | Matcher `/api/v1/admin/**` → `hasRole("ADMIN")` в `SecurityConfig` (защита всего префикса, а не одного контроллера). Мерж `506c31c` |
| 04 | — | Меню-док слева, влит ff `b226a98`, развёрнут |

Направление «чат с управляющим агентом-планировщиком» (ветка `feature/agent-chat-planner-docs`)
в объём 1.3 **не входит** — это самостоятельный релиз **1.4**. Решение владельца по развилке
Б-1 из его spec: **вариант 1** — дефект починен здесь, в 1.3, отдельно, а не отложен до
поглощения чатом. Тикет 04 релиза 1.4 всё равно переиспользует `ImportConfirmService`,
поэтому фикс не пропадает.

## Out of Scope

- Изменение семантики LLM-разбора сверх необходимого для попадания в расписание
  (`ImportParserService` — трогаем только контракт полей `recurrenceTime`/weekday).
- Новые виды сущностей в чат-панели помимо Дело/Проект/Рутина/Повторение.
- Изменение модели Записи времени (одна ячейка = одна Запись).
- Отдельный «агент-планировщик» (`AgentJob`) — он про заметки-подсказки и в объём 1.3 не входит.
