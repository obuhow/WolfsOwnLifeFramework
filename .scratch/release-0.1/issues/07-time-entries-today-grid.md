# 07 — Запись времени + сетка «Сегодня» (клики/статусы)

**What to build:** Пользователь на экране Сегодня видит 15-минутную сетку дня (с учётом timezone) и ставит Запись времени: выбор Дела или ad-hoc текст без автосоздания Дела. Будущее пустое → запланирована; повторный клик снимает; прошлое пустое → выполнена. Не больше одной записи на ячейку. Список «на сегодня» справа показывает Дела/записи дня.
