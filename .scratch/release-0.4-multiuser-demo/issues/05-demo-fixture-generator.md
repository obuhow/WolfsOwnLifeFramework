# 05 — Генератор демо-фикстур

**Type:** task
**Status:** resolved
**Blocked by:** 01 — Модель пользователя

**What to build:** `DemoFixtureGenerator` — сервис, который наполняет **любого** переданного пользователя реалистичным набором данных, датированным относительно сегодняшнего дня. Без HTTP-эндпоинта и без UI: сервис остаётся в кодовой базе как основа трёх демо-профилей релиза 0.6.

> **Перенос в релиз 0.6.** Вместо единого набора фикстур для анонимного демо этот сервис станет генератором трёх выбираемых демо-профилей («Рабочий класс», «Мудрый фрилансер», «Свободный художник»), загружаемых в постоянный аккаунт гостя после регистрации по инвайту. Содержание профилей — декларативные файлы (тикет 05 карты 0.5–0.7). Код уже написан и смёржен в `develop` (`e5041d1`, `7b37f38`).

## Scope

Фикстуры **генерируются кодом от `LocalDate.now()` в таймзоне пользователя**, а не грузятся из SQL-дампа и не копируются из шаблонного аккаунта. Дамп протухает: через месяц демо покажет пустой Гант и пустое «Сегодня».

Обязательный состав — по каждому пункту утверждённой навигации 0.3 экран должен быть **непустым и осмысленным**:

- **Сферы жизни** — стандартные 9 через `LifeSphereSeeder`
- **Области жизни** — 3: «Работа», «Здоровье», «Развитие»
- **Проекты** — 4 с разными статусами и плановыми часами: «Редизайн сайта», «Разработка API», «Курс по Java», «Личные цели»
- **Дела** — 12–15, распределены по проектам, часть без проекта («Без проекта» группа обязана быть непустой), разные состояния: выполнено, в работе, в бэклоге
- **Записи времени** — за **последние 14 дней**, включая сегодня: 4–6 ч факта в день на рабочие дни, меньше в выходные, обязательный интервал «Сон» по настройкам пользователя. Сегодняшний день заполнен **частично** — до текущего часа, чтобы остаток нормы был ненулевым и осмысленным
- **Недельные планы** — на текущую и следующую ISO-неделю, чтобы Гант показал плановую и фактическую дорожки
- **Цели** — 3 с недельными бюджетами и метриками, связанные с Проектами
- **Синергия** — 5–6 связей с разным знаком влияния (+, 0, −)
- **Банк идей** — 4 идеи в разных состояниях
- **Заметки** — 3, одна с автором «Агент»
- **Зависимости проектов** — минимум одна, чтобы Гант показал связь
- **Бэклог** — непустой на текущую неделю, с группировкой по проектам

Все интервалы обязаны лежать на 15-минутной сетке и не пересекаться — иначе упрётся в `uq_time_entry_user_start`.

Генератор детерминирован при фиксированной дате: сид случайности задаётся явно, чтобы тест мог проверять конкретные значения.

## Pitfalls

- Статический SQL-дамп — главная ошибка этого тикета. Через месяц демо мертво.
- Пересечение интервалов ловится только уникальным индексом на `(user_id, start_at)` — генерировать последовательно, а не независимыми случайными слотами.
- «Сон» должен соответствовать `nightStart`/`defaultSleepEnd` пользователя, иначе экран «Сегодня» покажет противоречие с настройками.
- Не заполнять сегодняшний день целиком: тогда остаток нормы = 0 и главный экран не показывает свою идею.
