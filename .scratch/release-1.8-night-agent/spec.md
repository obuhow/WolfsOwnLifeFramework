# Релиз 1.8 — Ночной агент

Status: `needs-triage`
Release: `1.8`
Feature slug: `release-1.8-night-agent`
Depends on: `release-1.5-agent-chat-planner`, `release-1.6-demo-archetypes`
Tracker: local markdown

## Цель

Оставлять пользователю полезные заметки-подсказки по итогам фонового прогона агента,
не выдавая демонстрационный сценарий за автономное изменение расписания.

## Зафиксированные решения

- Ночной cron запускает `AgentJob` только для активных аккаунтов типа `REGULAR`.
- Демо-гость запускает агент вручную через существующий endpoint для текущего
  пользователя; демо-аккаунты не попадают в массовый ночной cron.
- Для среды демо требуется `WOLF_LLM_ENABLED=true`. При выключенном LLM интерфейс
  сообщает об условии эксплуатации, а не показывает фиктивный результат.
- Карточки остаются сущностью `Note`; тип передаётся тегом поверх `agent-suggestion`:
  `разогрев`, `инсайт`, `референс`.
- Длительность, внешние ссылки, RSS/видео и новая сущность карточки не обещаются.
- Любое действие, меняющее план или расписание, требует подтверждения пользователя;
  ночной агент в этом релизе пишет только заметки.

## Acceptance criteria

- Ручной запуск для текущего пользователя создаёт или обновляет ожидаемые заметки.
- Ночной запуск не затрагивает DEMO-аккаунты.
- В выключенной LLM-конфигурации нет ложного «успешно создано».
- Заметки группируются по тегам без добавления новых типов сущностей.
- Агент не меняет Записи времени, Дела, Цели или расписание без подтверждения.

## Out of scope

- Автономная запись в расписание.
- Подключение внешних новостных, видео- или музыкальных источников.
- Новый механизм авторизации административного endpoint; существующий дефект role-gate
  уже ведётся в `release-1.3-tech-debt/bugs/03-admin-role-gate.md`.
