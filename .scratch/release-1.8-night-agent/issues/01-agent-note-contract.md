# Тикет 01 — Контракт заметок агента

Status: needs-triage
Blocked by:
Type: task

## Вопрос

Сделать результат ночного прогона предсказуемым для существующей сущности `Note`.

## Что сделать

- сохранить `agent-suggestion` как общий маркер источника;
- добавить согласованный набор тегов `разогрев`, `инсайт`, `референс`;
- определить правила повторного прогона: не плодить одинаковые заметки без изменения
  контекста и не удалять пользовательские заметки;
- показать источник и тип заметки нейтрально, без обещаний длительности или внешней ссылки.

## Testing Decisions

- Каждая созданная агентом заметка имеет источник и допустимый тип.
- Неизвестный тип не ломает выдачу и не становится новой сущностью.
- Повторный запуск с тем же входом не создаёт неконтролируемый дубль.
- Пользовательские заметки не удаляются и не переписываются агентом.
