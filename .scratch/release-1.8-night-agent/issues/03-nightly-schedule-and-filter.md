# Тикет 03 — Ночной cron и фильтр аккаунтов

Status: needs-triage
Blocked by: 01, 02
Type: task

## Вопрос

Закрепить безопасный массовый запуск ночного агента и его наблюдаемость.

## Что сделать

- сохранить фильтр `REGULAR` + `ACTIVE` для `runForAllUsers()`;
- не смешивать массовый и ручной пути `runForUser`;
- логировать количество отобранных аккаунтов, успешных прогонов и ошибок без секретов;
- покрыть расписание тестом, что DEMO не расходует ночную LLM-квоту.

## Testing Decisions

- В список массового прогона попадают только активные REGULAR.
- DEMO исключён независимо от наличия готовых фикстур.
- Один сбой не останавливает обработку остальных аккаунтов.
- Логи не содержат ключи, промпты с персональными данными или полный ответ провайдера.
