# Тикет 02 — Ручной прогон для демо и конфигурация LLM

Status: needs-triage
Blocked by: 01
Type: task

## Вопрос

Сделать ручную кнопку «Смоделировать ночь» честной и пригодной для демо.

## Что сделать

- использовать путь `runForUser(currentUser)` для ручного запуска;
- явно отображать состояние `WOLF_LLM_ENABLED` и результат прогона;
- не возвращать успешный результат, если LLM выключен или конфигурация неполна;
- оставить все возможные записи расписания и другие мутации за пределами ручного
  прогона либо за явным подтверждением.

## Testing Decisions

- На демо-профиле с включённым LLM ручной запуск создаёт заметки.
- На выключенной конфигурации пользователь получает объяснение, а не пустой успех.
- Ручной запуск DEMO не блокируется фильтром массового cron.
- Ошибка провайдера видна и не выдаётся за созданные карточки.
