# Тикет 03 — Детерминированный расчёт и матрица

Status: needs-triage
Blocked by: 01, 02
Type: task

## Вопрос

Показать влияние подтверждённой Идеи на Синергию и горизонт проекта без расчётов
в LLM.

## Что сделать

- считать результат по сохранённым часам, весу, текущему факту и правилам what-if;
- передавать в расчёт явные входы и возвращать объяснимый результат;
- показать в матрице знак и число типографикой, без красного/зелёного вердикта;
- при недостатке данных честно показывать «не рассчитано», не подставлять нули.

## Testing Decisions

- При одинаковых входах результат стабилен.
- Уменьшение доступного темпа на `weeklyHours` использует ту же формулу, что 1.7.
- Вес `0` не создаёт искусственного влияния.
- Недостаток данных не меняет сроки и не создаёт Записи времени.
- HTTP и UI показывают одинаковые значения и входные параметры расчёта.
