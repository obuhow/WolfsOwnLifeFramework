# Тикет 01 — Часы Идеи и вес Синергии

Status: needs-triage
Blocked by:
Type: task

## Вопрос

Расширить модель минимальными числовыми полями и сохранить обратную совместимость.

## Контракт

- `Idea.weeklyHours`: неотрицательное число часов в неделю, nullable для старых идей;
- `Synergy.weight`: целое число от `−5` до `+5`, nullable только на этапе миграции;
- существующий `impact` остаётся и продолжает отображаться для старых данных.

## Что сделать

- добавить миграцию и валидацию полей;
- расширить API DTO и страницу редактирования;
- определить значения для уже существующих записей без выдумывания факта;
- добавить интеграционные тесты чтения/записи и проверки диапазонов.

## Testing Decisions

- Старые записи читаются без ошибки.
- Значение вне `−5..+5` отклоняется.
- Отрицательные часы отклоняются, `null` допустим для идеи без оценки.
- Вес не подменяет ручной `impact` автоматически.
