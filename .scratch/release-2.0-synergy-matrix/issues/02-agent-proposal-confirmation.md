# Тикет 02 — Предложение агента и подтверждение

Status: needs-triage
Blocked by: 01
Type: task

## Вопрос

Провести оценку через чат-агента, но оставить решение за пользователем.

## Что сделать

- добавить в контекст агента существующие Проекты, Идеи, Сферы и фактическую нагрузку;
- принимать предложение часов, веса и текстового обоснования в структурированном DTO;
- показывать предложение как черновик до подтверждения;
- подтверждение записывает значения атомарно; отказ не меняет модель;
- не принимать произвольный ответ LLM как число без серверной валидации.

## Testing Decisions

- Предложение не меняет `Idea`/`Synergy` до подтверждения.
- Отказ и истечение черновика не оставляют частичных полей.
- Невалидное число или неизвестный объект не приводит к записи.
- Подтверждение доступно только владельцу текущего аккаунта.
