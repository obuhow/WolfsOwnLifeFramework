# Тикет 02 — Шаги 1–2: выбор стартового профиля и приветственное окно

Status: resolved
Blocked by: 01 (resolved)
Type: task

Шаги заявки: 1 (выбор стартового профиля), 2 (приветствие). Сквозная нумерация: **1–2 из 15**.

## Вопрос

Довести точку входа тура: экран выбора стартового демо-профиля (существует) и **новое**
приветственное окно по центру экрана с текстом-знакомством, ведущее на «Утренний обход».

## Что есть сейчас (доказательство контекста)

Шаг 1 заявки **уже реализован** целиком (релиз 0.6, тикеты 01/02):

- `web/src/components/ProfileLoadView.vue` — маршрут `/onboarding/profile`, «первый экран
  после регистрации по инвайту» (`:20`), грузит профиль через
  `POST /api/v1/onboarding/load-profile` (`:42`);
- `web/src/components/ProfileChoiceList.vue:42,48,54` — три профиля с ровно теми
  `displayName`, что в заявке: «Рабочий класс», «Мудрый фрилансер», «Свободный художник»;
- `assets/profiles/worker-class.json`, `wise-freelancer.json`, `free-artist.json` — данные;
- после загрузки профиля переход на тур: `ProfileLoadView.vue:53` —
  `window.location.hash = '#/onboarding/tour'` → `OnboardingTourEntry.vue` → `startTour()`;
- гейт маршрутизатора молчит, пока тур активен (`main.js:186`, `!isTourActive()`).

Чего нет: **приветственного окна** (шаг 2). Сейчас первый шаг тура — сразу подсказка у
пункта «Утренний обход» с текстом про содержимое раздела (`OnboardingTour.vue:44-48`),
без знакомства с ведущим.

Формулировка заявки для шага 1 («Пользователь переходит по ссылке, например из репозитория,
на демо-версию») описывает **демо-режим** (`CONTEXT.md`: «Демо-режим» — кнопка на
неавторизованном экране), а не онбординг по инвайту. Оба пути ведут к одному экрану выбора
профиля — в тикете это только уточнение текста, кода не касается.

## Что сделать

### Шаг 1 — без изменений кода

Экран выбора профиля работает как есть. Проверить только, что вход через **демо-режим**
(кнопка на неавторизованном экране) тоже приводит к запуску тура — если нет, зафиксировать
как отдельный баг, а не чинить здесь молча.

### Шаг 2 — приветственное окно (`placement: 'center'`, движок из тикета 01)

Первый шаг массива `STEPS`: модальное окно по центру, вырез держится под пунктом NAV
«Утренний обход», чтобы пользователь мог продолжить.

Текст (заявка, без правок по существу — противоречий с глоссарием нет; 🐺 по ADR-0008):

> 🐺 **Давайте знакомиться!**
>
> Я — WOLF, ваш помощник по самостоятельной оцифровке жизни и управлению потоком собственных
> дел. Следуйте инструкциям, и я покажу, как сделать первые шаги на пути к самооцифровке.
> Нажмите на вкладку «Утренний обход».

Тип завершения: `await: 'nav'`, `key: 'morning'` (существующий `data-tour-target` в
`App.vue:45`).

Счётчик: «шаг 1 из 15».

### Формулировки

Тон текста заявки совпадает с зафиксированным голосом продукта (`CONTEXT.md`: «Уютно. Тихо.
Под вашим контролем»). **Не использовать** формулировку «одно тёплое место» — она в
`CONTEXT.md` осталась исторически, но в новых текстах не применяется.

## Testing Decisions

  drawer-механика тикета 01 работает.
- `npm run build` зелёный.

## Out of Scope

- Вход через демо-режим — только проверка, починка (если понадобится) отдельным багом.

## Answer (resolved, 2026-09-01)

Status: resolved

- **Приветственное окно (шаг 2 заявки, «шаг 1 из 15»)** реализовано движком тикета 01 как
  первый элемент массива `web/src/onboardingSteps.js` (`n: 1`, `placement: 'center'`,
  `await: 'nav'`, `key: 'morning'`, `hole: 'morning'`). Текст заявки перенесён без правок по
  существу; 🐺 — под ADR-0008. Вырез держится под пунктом «Утренний обход», окно центрируется
  (`OnboardingTour.vue`, `isCentered` + `tooltipStyle` с `translate(-50%,-50%)`), поэтому
  пункт остаётся кликабельным и засчитывает шаг.
- **Экран выбора профиля (шаг 1 заявки)** не потребовал изменений: `ProfileLoadView.vue`
  грузит профиль и уводит на `#/onboarding/tour` как в релизе 0.6.
- **Вход через демо-режим тур НЕ запускает** — проверено и вынесено в баг
  `bugs/01-demo-mode-skips-tour.md` (демо-аккаунт создаётся с `onboardingCompletedAt` уже
  проставленным — `DemoRegisterService.java:71`, — поэтому онбординг-гейт `main.js:186`
  пропускает пользователя мимо тура). Починка — за владельцем, не сделана молча.
- `npm run build` и `npm test` зелёные (контракт шага 1 покрыт `onboardingSteps.test.mjs`).
