## Вопрос

Объяснить сущность «Рутина», провести через создание рутины с недельной квотой, затем
показать страницу «План нагрузки» и правку норм времени по проектам.

## Доказательство расхождений

### Шаг «Рутины»: «установите норму "30 минут в день"» — в модели только недельная квота

- `api/src/main/java/ru/wolf/api/routine/Routine.java:52-53` — единственное поле нормы:
  `@Column(name = "weekly_hours", nullable = false, precision = 8, scale = 2)`;
- форма: `web/src/components/RoutinesView.vue:160` — одно поле «**Недельная квота, ч**»
  (`form.weeklyHours`, `type="number"`, `min="0"`, `step="0.25"`), обязательное;
- в списке рутина отображается как `{{ item.weeklyHours }} ч/нед` (`:142`);
- дневной нормы **нет** ни в модели, ни в API (`routine/dto/RoutineRequest.java`), ни в UI.

**Решение владельца (реш. D):** переписать шаг на недельную квоту — «3,5 ч в неделю».
Модель и форма не меняются, миграции БД нет.

### Шаг «Рутины»: «помогает ИИ понимать ваш уровень энергии… посоветует снизить нагрузку»

Такой функциональности не существует: `Routine` не связана ни с рекомендациями, ни с
нагрузкой проектов (поля — `title`, `description`, `weeklyHours`, `color`, `icon`,
`archived`); модулей-советников в `api/src/main/java` нет.

**Решение владельца (реш. B):** про сон — **только** «рутины видны в общей нагрузке», без
обещаний советов ИИ. Советник по энергии в объём 1.2 не входит.

Термин «**Рутина**» до этой прожарки **отсутствовал в глоссарии** `CONTEXT.md` (0 упоминаний),
хотя сущность живёт в коде с ранних релизов. Добавлен прожаркой релиза 1.2 (реш. F).

### Шаг «Кривая нагрузки»: страница и вкладка названы наоборот

Заявка: «Действие: Переход на страницу «**Бюджет**»… В разделе **План нагрузки** вы можете
гибко установить нормы времени».

Фактически (после релиза 1.1):

- «**План нагрузки**» — это **страница**: `LoadPlanView.vue:34` — `<h1>План нагрузки</h1>`,
  маршрут `/load-plan` (тикет 1.1-02 `resolved`; глоссарий: «С 1.1 — отдельный маршрут»);
- «**Бюджет**» — **первая вкладка** на этой странице (порядок вкладок Бюджет, Кривые,
  Лестница, Очередь — grill 1.1 реш. C, тикет 1.1-03 `resolved`);
- на вкладке Бюджет строка проекта несёт **ползунок «Часов в неделю»**
  (`BudgetTab.vue:180,201`) — это и есть «гибко установить нормы времени на каждый проект»
  из заявки.

Важное уточнение по существу (заявка помечена «нужна помощь чтобы лучше сформулировать»):
ползунок Бюджета пишет ставку **на текущую ISO-неделю** — `PUT /api/v1/gantt/week-plans`
(`BudgetTab.vue:24`, «Запись ставки → PUT … на текущую ISO-неделю»). Поэтому просьба заявки
«поднимите для одного из проектов загрузку **4 недели по 20 часов в неделю**» одним
движением ползунка **не выполняется**: для многонедельной кривой существует отдельный
инструмент «Распределить время» (ручной редактор, `ProjectDetailView.vue:495`, тикет 1.1-04
`resolved`), который перераспределяет часы по неделям при неизменной сумме.
