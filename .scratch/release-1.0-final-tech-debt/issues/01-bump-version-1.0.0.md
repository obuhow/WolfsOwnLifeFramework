# Тикет 01 — Бамп версии WOLF до 1.0.0 и приёмка в шапке

Status: resolved
Blocked by:
Type: task

## Вопрос

Релиз 1.0 должен поднять единый источник правды о версии до `1.0.0` в обоих файлах
сборки синхронно и убедиться, что шапка показывает новую версию (закрывает Б-3,
`bugs/03-header-version-not-bumped.md`).

## Что сделать

1. `web/package.json` — `"version": "0.6.0"` → `"version": "1.0.0"`.
2. `api/build.gradle` — `version = '0.6.0'` → `version = '1.0.0'` (без `-SNAPSHOT`,
   релизная сборка).
3. Не трогать `web/vite.config.js` (там `__APP_VERSION__` уже берётся из `pkg.version`)
   и `App.vue` (вывод `v{{ appVersion }}` уже на месте).
4. Закрепить правило в `README.md` (раздел релизы / чеклист): бамп `package.json` и
   `build.gradle` делается синхронно при каждом релизе.

## Testing Decisions

- `npm run build` в `web/` — собранный бандл содержит строку `1.0.0` (grep по `web/dist`).
- Гейт визуальных тикетов: сборка → пересоздание контейнеров → сверка хэшей с
  `web/dist` → аутентификация в браузере → инспекция DOM: в шапке рядом с `WOLF`
  видна `v1.0.0` (десктоп `.brand-version` и мобильный `.brand-version-sm`).
- Смена версии в файлах перед пересборкой отражается в шапке без правок `App.vue`.

## Out of Scope

- Отдельный API-эндпоинт версии (`/actuator/info`) — версия из фронтенд-сборки.
- Автоматическое проставление версии из git-тега/CI.

## Закрывает

Баг Б-3 (`bugs/03-header-version-not-bumped.md`). Перевести его `Status: open` → `resolved`.

## Answer

Реализовано в ветке `release-1.0/feature/01-bump-version` (от `origin/develop`).

Изменения:
1. `web/package.json` — `"version": "0.6.0"` → `"1.0.0"` (единый источник для
   `__APP_VERSION__` через `web/vite.config.js`).
2. `api/build.gradle` — `version = '0.6.0'` → `'1.0.0'` (релизная сборка, без `-SNAPSHOT`).
3. `README.md` — бейдж версии `0.6.0` → `1.0.0`; раздел «Статус и дорожная карта»
   обновлён на `v1.0.0` и релиз 1.0.
4. `README.md` — закреплено правило синхронного бампа: цитата-чеклист «единая версия»
   в двух файлах сборки, шапка берёт версию из `package.json` без правок `App.vue`.
   `App.vue` и `vite.config.js` не трогались (по Out of Scope тикета).

Приёмка (Testing Decisions, build-гейт):
- `npm run build` в `web/` собрался как `wolf-web@1.0.0`.
- Бандл `dist/assets/index-*.js` содержит инлайненную константу `a=`1.0.0`` — это
  `appVersion`, который выводит шапка (`.brand-version`/`.brand-version-sm`,
  `App.vue:282,394`). Старой строки `0.6.0` в бандле нет.
- Полный визуальный гейт (пересборка контейнеров → аутентификация в браузере →
  инспекция DOM `v1.0.0`) выполняется на общем этапе приёмки визуальных тикетов
  релиза; механизм подстановки версии подтверждён на уровне бандла.

Б-3 закрыт (`Status: resolved`). Статус исходного 0.6-08 не трогался — по решению
владельца (баг был в несоблюдении правила бампа, не в механизме отображения).
