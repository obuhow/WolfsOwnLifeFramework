# Тикет 06 — Порядок шапки: Приветственный тур + Администрирование

Status: ready-for-agent
Blocked by: 07
Type: task

## Вопрос

Две правки навигации в шапке сайта (Доработка 2 заявки, разбита на два под-пункта):

1. Ссылка «Приветственный тур» должна стоять **между** «Документация» и «Настройки».
2. Для пользователя с ролью ADMIN — вкладка «Администрирование» **сразу после**
   «Документация» (перед «Настройки» и перед «Приветственный тур»).

## Что сделать

### 2.1 Порядок «Приветственный тур»

В `web/src/App.vue` массив `NAV` (строки 84-93) сейчас:
```
{ kind:'link', label:'Документация', to:'/docs', tour:'docs' },
{ kind:'group', key:'settings', label:'Настройки', ... },
```
Добавить между ними элемент-ссылку на тур. Тур сейчас открывается маршрутом
`/onboarding/tour` (main.js:68) и кнопкой в шапке (App.vue:358-361, `Приветственный тур`).
Решение: перенести существующую кнопку тура в позицию между «Документация» и
«Настройки» внутри `NAV` как `{ kind:'link', label:'Приветственный тур', to:'/onboarding/tour', tour:'intro' }`,
убрать дублирующую отдельную кнопку (или оставить как есть, если она вне NAV — тогда
просто добавить ссылку в NAV и удалить старую кнопку, чтобы не было двух).

### 2.2 Вкладка «Администрирование» (только ADMIN)

- `loadUser()` в `App.vue` (строки 228-249) читает `auth/me` и кладёт `username`;
  добавить чтение `data.role` в `isAdmin` (ref).
- В `NAV` после «Документация» (перед «Приветственный тур») добавить:
  ```js
  { kind:'link', label:'Администрирование', to:'/admin/users', adminOnly:true },
  ```
  и в рендере пункта NAV делать `v-if="!item.adminOnly || isAdmin"`.
- Маршрут `/admin/users` уже зарегистрирован? Проверить `main.js`: `/admin/invites`
  есть (строка 114), `/admin/users` — **нет**. Добавить маршрут
  `{ path:'/admin/users', component: AdminUsersView, meta:{requiresAuth:true} }`
  и создать `AdminUsersView.vue` (или расширить `AdminInvitesView.vue` вкладками
  «Инвайты» / «Пользователи»). Админ-API готов: `GET /admin/users?includeDemo`,
  `POST /admin/users/{id}/block`, `POST /admin/users/{id}/delete` (с телом
  `DeleteUserRequest`) — `AdminController.java:43-90`.

## Testing Decisions

- Браузерная приёмка (USER `obuhov`, роль ADMIN): в шапке порядок
  Документация → Администрирование → Приветственный тур → Настройки.
- Под обычным USER (роль USER): вкладка «Администрирование» не видна; порядок
  Документация → Приветственный тур → Настройки.
- Клик «Администрирование» → `/admin/users` показывает список пользователей с
  действием удаления и фильтром «включая демо».
- Клик «Приветственный тур» → запускает тур (поведение как у старой кнопки).

## Out of Scope

- Новые админ-права/роли — достаточно существующей ADMIN.
- Выдача инвайтов — уже реализована (`/admin/invites`, `AdminInvitesView.vue`); тикет
  только выносит «Администрирование» в шапку и добавляет просмотр/удаление пользователей.
