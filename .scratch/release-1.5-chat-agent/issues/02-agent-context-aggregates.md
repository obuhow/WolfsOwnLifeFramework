# Тикет 02 — Контекст агента и динамика расписания

Status: needs-triage
Blocked by:
Type: task

## Что сделать

Собрать узкий базовый срез активных Проектов, Целей и Рутин и вычисляемое описание
динамики расписания за доступный период: часы по проектам/Областям/Рутинам,
план/факт и тренды.

## Зафиксированные решения

В LLM не отправляются сырые тысячи 15-минутных Записей времени. Числа считает код
через существующие агрегирующие сервисы, модель только интерпретирует их.

## Testing Decisions

- Все числа контекста воспроизводимы кодом.
- Пустая история обозначается явно, а не заменяется выдуманными нулями.
- Контекст ограничен текущим пользователем и текущей сессией.
- Большой контекст не приводит к неограниченному запросу к провайдеру.
