# Тикет 06 — Прозрачность контекста

Status: needs-triage
Blocked by: 05
Type: task

## Что сделать

Показать пользователю, какой агрегированный срез ушёл во внешний LLM: период,
Проекты/Цели и основные числовые агрегаты без раскрытия секретов провайдера.

## Зафиксированные решения

Внешняя модель допустима, если пользователь видит объём переданного контекста.
Тумблер детализации и выбор модели в UI в MVP не вводятся.

## Testing Decisions

- Экран прозрачности соответствует фактическому payload, а не отдельному пересказу.
- Ключи и секреты не показываются.
- Пустые и скрытые поля явно обозначаются.
- В выключенном LLM-режиме экран объясняет причину недоступности.
