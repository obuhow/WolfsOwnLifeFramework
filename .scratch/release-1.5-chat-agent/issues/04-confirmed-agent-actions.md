# Тикет 04 — Предлагаемые действия и подтверждение

Status: needs-triage
Blocked by: 03
Type: task

## Что сделать

Расширить ответ агента машинно-читаемым предлагаемым действием: создать, изменить
или удалить сущность с полями и целевым объектом. Применять его только после
явного подтверждения через существующие доменные сервисы.

## Зафиксированные решения

Агент может менять существующие данные, но никогда молча. Одно подтверждение должно
быть атомарным и повторная отправка не должна дублировать запись.

## Testing Decisions

- До подтверждения БД не меняется.
- Отказ и истечение предложения не меняют БД.
- Невалидные поля дают понятную ошибку без частичной записи.
- Подтверждение повторно не создаёт ту же Запись времени.
