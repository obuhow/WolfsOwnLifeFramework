# Тикет 01 — Хранение переписки и история API

Status: needs-triage
Blocked by:
Type: task

## Что сделать

Создать `ChatSession`/`ChatMessage`, миграцию следующей версией Flyway после V42 и API
чтения/добавления сообщений для текущего пользователя.

## Зафиксированные решения

История сохраняется между сессиями и входит в контекст агента. Чужая переписка не
доступна. Удаление истории — отдельное действие пользователя, не побочный эффект
очистки демо-профиля.

## Testing Decisions

- Сообщения переживают перезагрузку и повторное открытие панели.
- Сессии изолированы по пользователю.
- Пагинация/лимит истории не меняют порядок сообщений.
- Миграция проходит на чистой и существующей базе.
