# Тикет 05 — Чат-панель «＋»

Status: needs-triage

Type: task

## Что сделать

Превратить существующую `ImportChatPanel.vue` в диалоговую панель: лента сообщений,
история, ответ агента, превью действия и кнопка «Подтвердить».

## Зафиксированные решения

Импорт неструктурированного текста остаётся намерением того же агента, отдельного
режима не добавляется. Панель не должна молча скрывать ошибки авторизации или записи.

## Testing Decisions

- Сообщения отображаются в порядке ответа сервера.
- Превью действия отличается от уже применённого действия.
- После подтверждения UI показывает фактически созданные записи.
- Существующий импорт каналов не ломается.
