# Тикет 07 — Доступ демо-профиля и лимит

Status: needs-triage
Blocked by: 03, 05
Type: task

## Что сделать

Разрешить чат демо-аккаунту на синтетических данных и ограничить дневное число
запросов по существующему паттерну `ImportBotDailyUsage`.

## Зафиксированные решения

Демо может обращаться к внешнему LLM, поэтому лимит обязателен. Демо не получает
доступ к реальным данным; ручной запуск ограничивается текущим аккаунтом.

## Testing Decisions

- Демо видит только свой профиль и его агрегаты.
- После лимита запрос не уходит провайдеру и пользователю показана причина.
- REGULAR-пользователь не наследует лимит DEMO.
- Счётчик лимита устойчив к параллельным запросам.
