# Тикет 03 — Порт агента и чат-эндпоинт

Status: needs-triage
Blocked by: 01, 02
Type: task

## Что сделать

Добавить `AgentChatPort`, HTTP- и fake-адаптеры, сервис и endpoint сообщения с
ответом, историей и моделью из конфигурации `wolf.llm.model`.

## Зафиксированные решения

Один встроенный агент-планировщик и одно окно. Системный prompt задаёт разработчик;
выбора модели в UI нет. Тесты используют fake-адаптер.

## Testing Decisions

- Ответ сохраняется в историю только после успешного ответа провайдера.
- Ошибка провайдера видима и не создаёт фиктивного сообщения.
- Пользователь не может выбрать чужую сессию.
- `wolf.llm.enabled=false` даёт честный недоступный статус.
