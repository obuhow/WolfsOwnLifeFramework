# 18 — Планирование: переименование Гантта + плановые часы в левой колонке + равномерное распределение + суммарная плановая нагрузка

**What to build:** Страница «Диаграмма Ганта» переименовывается в **Планирование** (`/gantt` → `/planning`, старый путь редиректит). В левой колонке рядом с названием Проекта — **плановые часы** проекта (и накопленный факт мелким шрифтом, без сравнения-оценки). При создании/редактировании Проекта — два взаимоисключающих чекбокса: **«Равномерно распределить время на проект по дням»** и **«Равномерно распределить время на проект по будням»**; при выборе плановые часы Проекта раскладываются по датам проекта и агрегируются в «План на неделю» (0.1) по ISO-неделям. Под диаграммой — блок **суммарной плановой нагрузки** (капасити): по неделям сумма плановых часов всех проектов против доступных часов пользователя (`available_weekly_hours` из тикета 10), с нейтральной дельтой.

**Blocked by:** 09 — Честный прогноз Gantt (страница переименовывается и получает дорожку прогноза); 10 — Каскад ресурсов (нужна настройка `available_weekly_hours`).
