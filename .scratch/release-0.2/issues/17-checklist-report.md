# 17 — Отчёт «Чек-лист»: история дневных чек-листов + отметки переключений

**What to build:** Страница `/reports/checklist` и endpoint `GET /api/v1/reports/checklist?from=&to=` — история по дням: пункты Чек-листа дня (тикет 16) с отметками выполнения и **Отметки переключений** из Фокус-сессий (тикет 13, Task control / review). Отчёт — это **зеркало факта, а не оценка**: считаем «отмечено N из M», показываем, куда уходили переключения, и не выводим ни процентов выполнения плана, ни стриков, ни «пропущенных дней». Экспорт в markdown/CSV — чтобы отчёт можно было положить в Заметку (тикет 04).

**Blocked by:** 04 — Заметки (кнопка «Сохранить как Заметку» пишет в модель Заметок); 13 — Режим фиксации времени (нужны отметки переключений); 16 — Чек-лист дня (нужны пункты).
