# 16 — Сегодня: блок «Бэклог недели» с планом часов x/y + Чек-лист дня

**What to build:** На страницу «Сегодня» добавляются два блока. **(а) Бэклог недели** — список Дел текущей ISO-недели с показателем часов **x/y**, где `x` — фактически уделённое время (сумма Записей времени со статусом «выполнена» по этому Делу за текущую ISO-неделю), `y` — плановые часы элемента бэклога (тикет 15). Итог по блоку — сумма x / сумма y. **(б) Чек-лист дня** — пользователь накидывает первоочередные дела на сегодня (свободный текст или ссылка на Дело) и отмечает галочками выполнение. Пункт чек-листа ≠ Дело и ≠ Запись времени: это лёгкий список намерения на день, он ничего не планирует и никуда не разносит часы. Невыполненные пункты **не переносятся автоматически** и не подсвечиваются — только ручная кнопка «перенести на завтра».

**Blocked by:** 15 — Бэклог месяца + панель (нужны `planned_hours` у элемента бэклога).
