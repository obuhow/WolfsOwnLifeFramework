# 09 — Честный прогноз Gantt: скользящее среднее фактических часов + месячная корректировка

**What to build:** `GET /api/v1/gantt/forecast` — для каждого Проекта прогноз даты окончания. Алгоритм: скользящее среднее фактических часов за последние 4 недели (из Записей времени 0.1), оставшиеся часы = плановые часы проекта − накопленный факт, прогноз недель = остаток / среднее. Если среднее ≈ 0 — прогноз "неопределён". План (даты проекта) замораживается на календарный месяц, прогноз пересчитывается еженедельно от факта. UI: на Гантте две дорожки — "план" (заморожен) и "прогноз" (пересчитан), разница видна без сигнализации. **Гант отвечает "когда реально закончу при текущем темпе", а не "когда обещал".**

**Blocked by:** 02 — Цели (нужны фактические часы по неделям); 08 — Зависимости (прогноз блокированных проектов учитывает финиш блокеров).
