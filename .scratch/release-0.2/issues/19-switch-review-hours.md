# 19 — Разбор переключений: добровольное превращение отметок в часы по Проектам

**What to build:** Пользователю нужны честные часы **по каждому Проекту**, но в момент переключения ему нельзя навязывать ввод минут — иначе фиксация перестаёт быть в один тап и режим Фокуса умирает. Поэтому разбор вынесен отдельным необязательным шагом: при закрытии Фокус-сессии (или позже, в конце дня) экран **«Разбор переключений»** показывает отметки сессии и предлагает превратить их в Записи времени на соответствующие Дела/Проекты. Пользователь может проставить минуты, может нажать «оставить как есть» — данные не теряются ни в одном из вариантов. **Ничего не применяется автоматически**, повторный разбор возможен позже.

Мотивационная рамка: экран называется «Разбор», а не «Уточните учёт»; «оставить как есть» — равноправная кнопка, а не пропуск; отсутствие разбора нигде не подсвечивается и ни на что не влияет, кроме детализации часов.

**Blocked by:** 13 — Режим фиксации времени (нужны Фокус-сессии и отметки).

**Status:** ready-for-agent

## Логика

- [ ] `GET /api/v1/focus/{id}/review` — отметки сессии + предлагаемая раскладка: для отметки с `minutes` — округление вверх до 15 мин, для отметки без `minutes` — предложение `null` (пользователь вводит сам)
- [ ] `POST /api/v1/focus/{id}/review/preview {allocations: [{distractionId, deloId, minutes}]}` — **dry-run**: какие ячейки будут переписаны с Главного дела на Дело переключения, какие заняты чужими Записями
- [ ] `POST /api/v1/focus/{id}/review/apply {allocations: [...]}` — применение: часы вычитаются у Главного дела и записываются на Дело переключения по правилам материализации из тикета 13 (границы 15 мин, отдельные интервалы, без склейки через занятый слот)
- [ ] Разнос по Проектам не выполняется здесь: Записи ссылаются на Дела, а часы по Проектам считает Режим учёта часов 0.1 (`primary_only` / `all_projects`)
- [ ] Сумма аллокаций > длительности сессии → 400 с пояснением и предложением ужать (без формулировок вины)
- [ ] Идемпотентность: повторный `apply` для уже разобранной отметки не дублирует часы; отметка помечается `applied_at`
- [ ] Отмена разбора: `POST /api/v1/focus/{id}/review/revert` — возврат ячеек Главному делу
- [ ] Отсутствие разбора не влияет ни на прогноз (тикет 09), ни на факт целей (тикет 02) — просто часы остаются на Главном деле

## UI

- [ ] Экран разбора после `stop` сессии: список отметок, поле минут с быстрыми пресетами (15 / 30 / 45 / 60), кнопка «Оставить как есть» той же визуальной силы, что и «Применить»
- [ ] Возврат к разбору позже: карточка сессии в «Сегодня» и в Отчёте (тикет 17) с кнопкой «Разобрать»
- [ ] Ни бейджей, ни счётчиков «неразобранных сессий», ни точек-уведомлений
- [ ] Предпросмотр показывает результат словами: «45 мин уйдут с “Spring Security” на “Ревью WOLF”»
