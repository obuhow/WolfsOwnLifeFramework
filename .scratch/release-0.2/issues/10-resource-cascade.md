# 10 — Каскад ресурсов: визуализация влияния сдвига на другие Цели

**What to build:** При ручной корректировке срока Проекта (plan dates) система показывает, какие Цели пострадают: суммарный недельный бюджет по всем активным Целям vs доступных часов в неделю у пользователя (настройка, default 30 ч). `POST /api/v1/projects/{id}/plan-shift-preview {newEnd}` — dry-run, возвращает список затронутых Целей с дефицитом часов. **Только отображение, решение за пользователем** — никаких автоматических перестроений. UI: диалог подтверждения сдвига с предупреждением "сдвиг повлияет на N целей, дефицит X ч/нед".

**Blocked by:** 09 — Честный прогноз Gantt (нужны прогнозы для каскада).
