# 07 — Утренний обход: агрегирующий endpoint + UI

**What to build:** `GET /api/v1/morning-digest` — один запрос для утреннего ритуала. Возвращает: (а) все активные Проекты с последними N=5 Заметками каждого (user+agent, свежие сверху), (б) очередь Дел в каждом Проекте (из 0.1, верхние 3), (в) 3 случайные Идеи из Банка (статус "в банке", при необходимости всплытия), (г) фактические часы текущей недели по каждой Цели vs бюджет. UI: страница "Утро" — список проектов с заметками и делами, блок идей, полоса "неделя по целям". Никаких красных индикаторов при недоборе часов — нейтральный серый.

**Blocked by:** 03 — Банк Идей; 06 — Фоновый агент (нужны подложки в digest).
