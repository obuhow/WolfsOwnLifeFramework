# 03. Адресация: лендинг на корне, приложение на отдельном адресе

Type: grilling
Status: open
Blocks: 06
Map: `.scratch/wayfinder-release-1.0-public-beta/map.md`

## Question

Как физически развести лендинг и приложение на одном домене, чтобы не сломать вход уже работающим пользователям?

Владелец выбрал схему «корень → лендинг, `/app` → сама система». Проблема в том, что **корень сейчас занят приложением**. В `web/nginx.conf`:

```
location / {
    try_files $uri $uri/ /index.html;
}
```

Это SPA-catch-all: любой неизвестный путь отдаёт `index.html` Vue-приложения. Отдать корень лендингу — значит переселить приложение, а у Vue-роутера есть собственные представления о том, где он живёт (`/morning`, `/calendar`, `/roadmap`, `/today`, редиректы 302 со старых маршрутов из 0.5).

Решить:

1. **Куда переезжает приложение**: подпуть `/app` на том же домене или поддомен (`app.<домен>`). У подпути цена — `base` во Vite, `history`-режим роутера, все абсолютные ссылки и редиректы 0.5; у поддомена — отдельный сертификат и настройка CORS/куки, зато приложение остаётся на корне своего хоста и в коде меняется меньше. **Оценить обе цены до выбора**, а не после.
2. **Что происходит со старыми ссылками**, которые уже могут быть в закладках у владельца: `/morning`, `/roadmap`, `/notes`. Редирект или обрыв.
3. **Куда ведёт кнопка «Войти»** с лендинга и куда попадает человек после логина.
4. **Что отдаётся по `/docs/`** — сейчас это отдельный контейнер `wolf-docs`; остаётся ли документация там же и ссылается ли на неё лендинг.
5. **Проверка**: приложение должно продолжать работать после переезда — прогнать вход, `Утренний обход`, `Ежедневник`, `Дорожную карту` в браузере, а не только собрать фронт.

## Definition of done

- Схема адресов зафиксирована в Answer с обоснованием выбора (подпуть или поддомен) и ценой, которую за него платим.
- Изменения применены: лендинг-заглушка (пустая страница-плейсхолдер достаточно — содержание делает тикет 06) на корне, приложение на выбранном адресе.
- Ручная проверка в браузере: вход, четыре ключевых экрана, старые ссылки ведут куда решено.
- `web/nginx.conf` и, если понадобилось, конфиг Vite обновлены; ничего не сломано в `docker compose up`.
