# 01: Иерархия проектов видна в Бэклоге и Утреннем обходе

**What to build:** Бэклог (Ежедневник-неделя и страница Бэклог) должен показывать вложенность
проектов так же, как Гантт и Утренний обход — отступы по глубине, маркер вложения и (опционально)
сворачивание поддерева. Утренний обход уже рендерит иерархию — тикет закрепляет это поведение и
добавляет приёмочную проверку; основной объём — приведение Бэклога к тому же виду.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Где сейчас (факты):**
- Утренний обход: `MorningDigestService.buildProjectTree` отдаёт `ProjectDigest` с `parentId`/
  `depth`; `web/src/components/MorningView.vue` уже рисует `marginLeft: depth*20` и сворачивание
  через `expanded`/`toggle`/`isVisible`/`hasChildren`. **Работает** — нужно не сломать и покрыть
  тестом/приёмкой.
- Бэклог недели (Ежедневник): `WeekView.vue` → `groupBacklogWithNorm` (`web/src/backlogGroups.js`)
  — плоский список групп `projectId`/`label`/`fact`/`plan`/`pending` **без** `parentId`/`depth`.
- Бэклог страницы: `BacklogView.vue` → `groupByProject` (там же) — тоже плоский.
- Дерево проектов целиком уже доступно фронту: `GET /gantt` возвращает `projects[]` с
  `parentId`/`depth` (`GanttService.buildProjectRows` → `walkTree`).

**Что сделать:**
- [ ] `groupBacklogWithNorm` и `groupByProject` (`web/src/backlogGroups.js`) возвращают для
      каждой группы `parentId` и `depth` проекта (берут из переданного списка `projects` по
      `projectId`; для «Без проекта» — `parentId: null`, `depth: 0`).
- [ ] `WeekView.vue` (бэклог недели) и `BacklogView.vue` рендерят вложенность: отступ
      `depth*<step>px`, маркер `└` для `depth>0`, сохраняя текущую логику полосы заполнения
      (`fillBarSegments`) и сортировку.
- [ ] Утренний обход: добавить приёмочную проверку (IT или ручную в браузере), что при наличии
      подпроектов карточки дочерних проектов видны с отступом и сворачиваются/раскрываются по
      родителю; не менять существующую логику `isVisible`/`toggle` без необходимости.
- [ ] Проверить, что бэклог месяца (если переиспользует те же хелперы) тоже не теряет
      иерархию; при необходимости распространить правку.
- [ ] `npm run build` зелёный; существующая вёрстка бэклога и Утреннего обхода не сломана
      (визуальная приёмка на живом стенде или в dev).

**Проверочный факт (приёмка):** проект с двумя уровнями вложенности (Корень → Потомок →
Лист) в Бэклоге и Утреннем обходе отображается тремя строками с нарастающим отступом; в Бэклоге
группа «Без проекта» остаётся последней и плоской.
