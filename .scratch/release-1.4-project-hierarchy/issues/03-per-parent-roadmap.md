# 03: У каждого родительского проекта — своя дорожная карта

**What to build:** На странице проекта (`ProjectDetailView`) появляется раздел «Дорожная карта» —
мини-Гантт, показывающий сам проект и **всех его потомков** (поддерево) с планом/фактом по
неделям. Это не новая сущность, а вид существующего Гантта, ограниченный корнем поддерева.

**Blocked by:** 01 (дерево в интерфейсе), 02 (в карте проекта тоже нужен roll-up часов)

**Status:** ready-for-agent

**Где сейчас (факты):**
- «Дорожная карта» = `GET /gantt` → `GanttView.vue`, строит дерево всех проектов
  пользователя (`GanttService.getGantt` → `buildProjectRows`/`walkTree`). Фильтры:
  `lifeAreaIds`, `onlyWithDates`, диапазон недель. Фильтра «по корню поддерева» нет.
- `ProjectDetailView.vue` уже показывает `children` (фильтр `projects` по `parentId`), но
  Гантта поддерева не рисует.
- Тикет 01 даёт фронту дерево проектов; тикет 02 даёт roll-up часов в `ProjectRow`.

**Что сделать:**
- [ ] Бэкенд: расширить `GET /gantt` необязательным параметром `rootId` (id проекта). При
      заданном `rootId` отобранный набор проектов сужается до самого проекта + всех потомков
      (рекурсивно по `parent`), с сохранением существующей логики `expandWithAncestors` и
      `walkTree` (глубина `depth` считается относительно корня поддерева — у корня `depth=0`).
      Не дублировать построение дерева — переиспользовать `buildProjectRows`.
- [ ] Бэкенд: при `rootId` применять roll-up из тикета 02 к этому поддереву, чтобы у корня
      карты часы = сумма поддерева.
- [ ] Фронт: в `ProjectDetailView.vue` добавить вкладку/секцию «Дорожная карта», которая
      делает `GET /gantt?rootId={projectId}` и рендерит те же строки проектов
      (`gantt-project-row` с `depth`/└/отступ, полосы plan/fact), что и общий Гантт — через тот
      же компонент/разметку, не копируя вёрстку.
- [ ] Проверить граничные случаи: проект-лист (карта = одна строка), проект без дат
      (показывается, т.к. в поддереве), `rootId` чужого/несуществующего проекта — 403/404 или
      пусто согласно контракту `GanttService`.
- [ ] `npm run build` + сборка API зелёные; навигация из списка `children` на карту проекта
      работает; общий Гантт без `rootId` не меняется.

**Проверочный факт (приёмка):** открытие проекта-родителя → «Дорожная карта» показывает только
его поддерево (сам проект + потомки) с корректными отступами и часами (с roll-up у корня);
общий Гантт по-прежнему содержит все проекты.
