# 04: Во всех дорожных картах — строка внизу с суммой всех трудочасов

**What to build:** В конце каждой дорожной карты (общего Гантта и карты проекта из тикета 03)
появляется итоговая строка «Итого»: сумма `totalPlanHours` по всем показанным проектам и, по
каждой неделе, сумма `plan`/`fact`/`pending` часов. Строка считается на фронте из уже полученных
`rows` — отдельного эндпоинта не требуется.

**Blocked by:** 02 (roll-up часов в `rows`), 03 (карта проекта)

**Status:** ready-for-agent

**Где сейчас (факты):**
- `ProjectRow` (`api/.../gantt/dto/ProjectRow.java`) несёт `totalPlanHours` и `cells[]`
  (`planHours`/`factHours`/`pendingHours`). Итоговой строки в DTO и в `GanttView.vue` нет.
- `GanttView.vue` рендерит строки проектов в цикле `v-for="p in projects"`; тикет 03 добавит
  тот же цикл для карты проекта.
- Тикет 02 обеспечивает, что у родителей `totalPlanHours` и ячейки уже включают потомков —
  значит сумма по `rows` даст корректный итог поддерева без двойного счёта.

**Что сделать:**
- [ ] Вынести вычисление итога в общий хелпер (напр. `web/src/backlogGroups.js` или отдельный
      `ganttTotals.js`): на вход — `rows` (с `totalPlanHours` и `cells[]`); на выходе —
      `{ totalPlanHours, perWeek: [{plan, fact, pending}] }`, где `perWeek[i]` = сумма по всем
      `rows` ячейки `i`.
- [ ] `GanttView.vue`: под таблицей проектов отрисовать строку «Итого» с итоговым
      `totalPlanHours` (через `formatHours`) и по каждой неделе — суммами `plan`/`fact`/
      `pending` из хелпера. Стиль — выделенная «footer»-строка, без красных состояний
      (контракт UI 0.3).
- [ ] Карта проекта (тикет 03): переиспользовать тот же хелпер и ту же «footer»-вёрстку, так
      чтобы итог считался по поддереву карты.
- [ ] Учесть «Без проекта»/фильтры: итог — по **показанным** `rows` (видимое поддерево), а не
      по всей БД. Если ни одного проекта нет — строку не рендерить.
- [ ] `npm run build` зелёный; сумма в «Итого» совпадает с ручной проверкой по `rows`
      (визуальная приёмка на живом стенде или в dev).

**Проверочный факт (приёмка):** строка «Итого» в общем Гантте = сумма `totalPlanHours` всех
показанных проектов, а по каждой неделе — сумма plan/fact/pending по этим проектам; в карте
проекта «Итого» = сумма по его поддереву (совпадает с roll-up у корня из тикета 02).
