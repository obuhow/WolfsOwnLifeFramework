# 05: Нормализация вариаций написания в две ступени

**What to build:** Разные написания одной активности не плодят лишние вопросы и Дела, но при
этом система не стирает молча различия, которые пользователь мог делать специально.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] **Ступень 1 (тривиальная, авто и молча):** обрезка пробелов, приведение регистра —
      «Сон»/«сон», «Java »/«Java» → одна активность
- [ ] **Ступень 2 (смысловая, через подтверждение):** «в спортзал»/«Спортзал»,
      «Клуб английского»/«Английский клуб» — предлагается объединить на одно Дело через
      `activity_mapping`, но только с явным подтверждением пользователя, не молча
- [ ] Механизм `activity_mapping` позволяет разным текстам ссылаться на одно Дело — переиспользуется
- [ ] Различающиеся по смыслу активности («Проект»/«Проект игры») НЕ склеиваются автоматически
- [ ] Тест: пара вариаций регистра сворачивается авто; смысловая пара требует подтверждения; несвязанные не трогаются
