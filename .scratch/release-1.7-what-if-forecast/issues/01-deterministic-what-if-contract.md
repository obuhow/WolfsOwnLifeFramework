## Вопрос

Зафиксировать единый детерминированный расчёт прогноза при заданном темпе.

## Что сделать

- вынести общий расчёт так, чтобы обычный forecast и what-if использовали одну формулу;
- принимать `weeklyHours` только как положительное число;
- при заданном значении не менять сохранённый факт и план;
- сохранить поведение для среднего ниже `0.5` и отсутствие прогноза там, где
  существующий контракт намеренно возвращает `null`.

## Testing Decisions

- Для 4/8/14/25 часов возвращается ожидаемая дата через `ceil(remaining / rate)`.
- Одинаковый вход даёт одинаковый результат независимо от вызывающего UI.
- Ноль, отрицательное число, NaN и переполнение отклоняются.
- Без what-if результат совпадает с текущим `GanttForecastService.forecast()`.
