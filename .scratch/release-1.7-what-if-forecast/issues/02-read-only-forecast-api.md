# Тикет 02 — Read-only API прогноза

Status: needs-triage
Blocked by: 01
Type: task

## Вопрос

Добавить явный API-контракт для расчёта what-if без записи состояния.

## Что сделать

- принять необязательный `weeklyHours` в DTO запроса прогноза;
- валидировать значение на границе API и возвращать понятную ошибку для плохого ввода;
- вернуть исходный темп, вычисленную дату и признаки отсутствия прогноза;
- не принимать через этот endpoint команды записи, purge или изменения расписания;
- покрыть HTTP-контракт интеграционными тестами.

## Testing Decisions

- Запрос без параметра совместим с существующим прогнозом.
- Запрос с каждым пресетом возвращает рассчитанную дату.
- Плохой параметр даёт 4xx, а состояние пользователя не меняется.
- Повторные запросы не создают новых сущностей.
