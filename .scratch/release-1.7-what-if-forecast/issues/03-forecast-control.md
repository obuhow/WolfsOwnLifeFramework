# Тикет 03 — Управление прогнозом на Дорожной карте

Status: needs-triage
Blocked by: 01, 02
Type: task

## Вопрос

Показать пресеты и результат what-if на существующей странице Дорожной карты.

## Что сделать

- добавить пресеты 4/8/14/25 и ручной числовой ввод в пределах API-контракта;
- показывать, что значение является сценарием, а не сохранённым планом;
- обновлять только производную прогноз-полосу и дату финиша;
- сохранять нейтральный визуальный контракт без красных алертов, процентов и теней.

## Testing Decisions

- Переключение пресета обновляет результат без перезагрузки страницы.
- Обновление страницы не превращает сценарий в сохранённый план.
- Пустой/сброшенный ввод возвращает прогноз по факту.
- Сценарий доступен на демо-профиле с историей и на обычном аккаунте с фактами.
