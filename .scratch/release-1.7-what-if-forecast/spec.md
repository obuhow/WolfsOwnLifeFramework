# Релиз 1.7 — Прогноз по факту (what-if)

Status: `needs-triage`
Release: `1.7`

Depends on: `release-1.5-agent-chat-planner`, `release-1.6-demo-archetypes`
Tracker: local markdown

## Цель

Дать пользователю честный ответ на вопрос «что будет с горизонтом проекта при
tемпе N часов в неделю». Это read-only производная от факта и не перестраивает
расписание.

## Зафиксированные решения

- Ввод — необязательное количество часов в неделю; MVP показывает пресеты `4`, `8`,
  `14`, `25` и допускает положительное числовое значение в согласованном диапазоне.
- Если ввод не задан, используется текущий расчёт по факту последних четырёх недель.
- Если ввод задан, он временно подменяет `weeklyAvg` в существующей формуле
  `ceil(remaining / weeklyAvg)`; результатом остаётся дата финиша.
- Порог `MIN_WEEKLY_AVERAGE = 0.5` сохраняется. Значения пресетов выше порога,
  поэтому прогноз для них не исчезает.
- Расчёт выполняет код. LLM может объяснить результат, но не вычисляет дату.
- Деньги, ставки, подработка и автоматическое изменение Записей времени в релиз
  не входят.

## Acceptance criteria

- Для одинаковых факта, проекта и входного темпа API возвращает одинаковую дату.
- Пустой ввод сохраняет действующий прогноз по факту.
- Некорректные, нулевые и отрицательные значения не попадают в расчёт.
- What-if не создаёт, не изменяет и не удаляет Записи времени.
- UI показывает входной темп и дату результата нейтральной типографикой, без
  красно-зелёного вердикта и процентного прогресс-бара.

## Out of scope

- Автоматическая перестройка расписания.
- Бюджеты и денежные сценарии.
- Свободный текстовый прогноз от LLM вместо серверного расчёта.
