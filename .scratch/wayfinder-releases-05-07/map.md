# WOLF 0.5–0.7 — Демо-стенд, навигация, документация, AI-импорт — Wayfinder Map

## Destination

Опубликованные `spec.md` + тикеты для **трёх релизов**, готовые к `implement`:

- **0.5 — Навигация и Документация**: новая структура меню (переименования Гант → Дорожная карта, Кривая нагрузки → План нагрузки, Сферы жизни → Диаграмма компетенций, Заметки/LLM Wiki → Личная база знаний), раздел `/docs` внутри приложения (Манифест Siberian Wolf, Сценарии использования, Технические инструкции).
- **0.6 — Демо-профили и Знакомство**: выбор одного из трёх преднастроенных профилей при первом входе по инвайту, тур всплывающими подсказками по основным экранам, финальный выбор «Оставить / Очистить профиль», повторная загрузка профиля в Настройках.
- **0.7 — AI-импорт записей**: чат-бот, превращающий свободный текст заметок в Дела, Проекты, Рутины и слоты расписания.

Плюс **релиз 0.4 приведён в согласие** с этими решениями: тикеты 05 и 06 закрыты как out of scope, тикет 08 переформулирован.

Карта пройдена, когда все три spec.md опубликованы, их тикеты заведены, и в 0.4 не осталось противоречащих им тикетов.

### Решения, принятые при черчении

Это исходные ограничения карты, а не результаты тикетов.

- **Вход в систему только по инвайту.** Анонимная кнопка «Попробовать демо» отменена. Демо-сайт — закрытый стенд: каждый гость получает настоящий постоянный аккаунт с загруженным профилем.
- **Первый вход = выбор профиля, а не ввод своего.** Форма «Загрузка профиля» с тремя вариантами ситуации (наёмный работник / фрилансер / художник) → загружается соответствующий профиль (Рабочий класс / Мудрый фрилансер / Свободный художник) с предзаполненными данными, которые гость правит в течение месяца.
- **После загрузки профиля — тур** всплывающими подсказками в стиле «Нажмите на пункт меню Дорожная карта…». В конце тура выбор: **Оставить предзаполненный профиль** или **Очистить профиль**.
- **«Очистить профиль» запускает три шага** (Проект → Цель → недельная норма) из тикета 08 релиза 0.4 — гость выходит на «Сегодня» со своим первым Проектом и своей нормой, а не в пустоту.
- **Повторная загрузка профиля** доступна в Настройках.
- **Источник профилей** — декларативные файлы (YAML/JSON) в репозитории + загрузчик, сдвигающий даты относительно сегодня. Правка профиля не требует пересборки Java.
- **Меню**: Бэклог, Банк идей и Отчёт «Чек-лист» переезжают в **Управление делами**. Импорт XLSX объединяется с Синхронизацией и становится подпунктом **Настроек**.
- **Четыре новых названия — переименования, не новые экраны**: Дорожная карта = Диаграмма Ганта; План нагрузки = Кривая нагрузки; Диаграмма компетенций = Сферы жизни; Личная база знаний = Заметки / LLM Wiki.
- **Манифест описывает только работающее.** Пункт Манифеста, чья «Реализация» ещё не существует, не публикуется, пока соответствующий тикет не закрыт. Манифест не содержит обещаний в настоящем времени.
- **AI-бот**: подтверждение запрашивается только там, где разбор неуверен или слот занят; однозначное пишется сразу. Каналы по порядку: **чат-панель в интерфейсе** → **Telegram** → **Max** (после research его bot API).
- **Повторяющиеся Дела** хранятся как одно Дело + правило через существующий `RecurrenceService`. Материализация 52 записей запрещена.
- **Тихий контракт 0.3 сохраняется** во всех трёх релизах: нет красных состояний, процентов, прогресс-баров, стриков и упрёков.

## Out of scope

- **Судьба гостевого аккаунта во времени** (истекает ли инвайт-аккаунт, GC заброшенных профилей) — операционный вопрос эксплуатации демо-стенда после публикации 0.6, не вопрос содержания самого spec.md; следующая карта или прямое решение владельца при появлении первых заброшенных гостей.
- **Голосовой ввод в бота импорта 0.7** — `POST /api/v1/notes/audio` существует для Заметок; распространение на `ImportParserService` не вошло в spec.md 0.7 (см. `## Out of Scope` этого релиза: «Разбор изображений/документов через бота» — голос упомянут отдельно как уже решённый канал для Заметок, не для импорта). Кандидат на будущее расширение 0.7, не текущий релиз.
- **Тур «что переехало» для существующих пользователей** после переименований 0.5 — spec.md 0.5 не вводит отдельный тур миграции; переименование проходит молча с редиректами 302, что и было решением тикета 04.
- **Правовая модель хостинга сверх research** (оферта, политика обработки, уведомление РКН, локализация БД) — research тикета 01 зафиксировал юридический ландшафт и риск как факт, но не спроектировал сами эти документы/меры; вне destination карты (три spec.md для 0.5–0.7), не блокирует их публикацию.
- **Дистрибутив самохостинга** (`docker compose up`, готовые образы в реестре, миграция со стенда) — не затронут ни одним из трёх релизов; отдельная будущая инициатива.

- **Анонимная демо-сессия** — эфемерные аккаунты `demo-<random>`, 24-часовой TTL, GC по расписанию, rate-limit по IP, `account_type=DEMO`. Отменено в пользу закрытого инвайт-стенда; тикет 06 релиза 0.4 закрывается.
- **Единый фиксированный набор демо-фикстур** — заменён тремя выбираемыми профилями; тикет 05 релиза 0.4 закрывается, его содержание переходит в 0.6.
- Открытая саморегистрация, подтверждение e-mail, восстановление пароля, SMTP, OAuth/SSO (унаследовано из 0.4).
- Совместная работа: общие Проекты, команды, шаринг сущностей. WOLF остаётся системой личного учёта.
- Тарифы, биллинг, лимиты по подписке.
- Реализация кода трёх релизов — карта доводит до опубликованных spec и тикетов, не дальше.
