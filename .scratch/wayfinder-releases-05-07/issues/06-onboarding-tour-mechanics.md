# Механика Знакомства: тур, финальный выбор, повторная загрузка

Type: grilling
Status: resolved
Blocked by: 04

## Question

Как именно работает тур всплывающими подсказками, и что происходит на его границах?

## Answer

### Тур ведёт (не сопровождает)

Тур **блокирует остальной интерфейс** и ждёт именно нужного клика — подсказка «Нажмите на пункт меню Дорожная карта» не переходит дальше, пока пользователь не кликнет ровно туда. Клик в другое место интерфейса не засчитывается (интерфейс заблокирован модальным затемнением, см. визуальный контракт ниже).

### Шаги и покрытие

**6–7 шагов** — по каждому из шести топ-пунктов меню (Утренний обход · Ежедневник · Управление делами · Управление потоком · Настройки · Документация), без детального покрытия каждого подпункта внутри разделов. Один клик = один пункт верхнего уровня.

### Прерывание

**Выход возможен в любой момент.** Финальный выбор «Оставить предзаполненный профиль / Очистить профиль» показывается сразу после выхода — гость не остаётся с профилем без спроса, даже если бросил тур на втором шаге.

### Возобновление

**Начинается заново** при следующем входе. Состояние тура не сохраняется в БД — простое поведение без промежуточного трекинга прогресса.

### Визуальный контракт подсказки

**Затемнение фона с вырезом под подсвечиваемый элемент** + текстовая подсказка рядом. **Без прогресс-бара** («шаг 3 из 7») — соответствует тихому контракту 0.3 (никаких индикаторов прогресса, процентов, стриков).

### Финальное окно

**Не требует отдельного подтверждения.** Клик по кнопке «Очистить» — это и есть подтверждение, без второго модального окна «вы уверены?». Соответствует тихому контракту: без красных кнопок, без предупреждающих иконок, без двойного клика для необратимого действия — сама кнопка формулируется явно («Очистить профиль»), это достаточно.

### Что удаляет очистка

Удаляются: **Проекты, Дела, Записи времени, Цели, Идеи, Заметки** — всё, что профиль создал.
Остаются: **Области жизни и 9 Сфер** (справочник, не создаются профилем заново).
**Недельная норма часов сбрасывается на дефолтную** системную величину (не на 0, а на стандартное значение по умолчанию — то же самое, что видит пользователь, регистрирующийся без профиля).

### Повторная загрузка в Настройках

**С предварительной очисткой** — те же правила, что и «Очистить профиль». Загрузка нового профиля (того же или другого) сначала удаляет всё, что создал текущий профиль, затем наполняет заново. Гость, ведший месяц свои записи и нажавший «Загрузить профиль», теряет свои данные — это ожидаемое поведение смены профиля, не инкрементальное слияние.

### Кто видит Знакомство

Используется существующий признак **`onboarding_completed_at`** из тикета 01 релиза 0.4 — отдельного признака для тура не создаётся. `admin` и личный аккаунт владельца уже прошли онбординг (или не должны его видеть) — управляется тем же полем.

### Мобильное поведение

**Тур работает на мобильном** через drawer-меню — та же ведущая механика: подсказка указывает открыть меню (например, «Откройте меню и нажмите Дорожная карта»), тур ждёт открытия drawer, затем клика по нужному пункту внутри него.

## Итоговый поток

1. Гость по инвайту → форма «Загрузка профиля» → выбор одного из трёх профилей → загружен (тикет 05).
2. Тур из 6–7 шагов, ведущий, с блокировкой интерфейса и вырезом-подсветкой, по топ-пунктам меню (drawer на мобильном — та же механика).
3. Выход из тура возможен в любой момент → сразу переход к шагу 4.
4. Финальный выбор: **Оставить предзаполненный профиль** / **Очистить профиль** — без второго подтверждения.
5. При «Очистить»: удаление Проектов/Дел/Записей времени/Целей/Идей/Заметок, сброс нормы на дефолт, Области жизни и 9 Сфер остаются → запуск трёх шагов (Проект → Цель → норма) из тикета 08 релиза 0.4.
6. Повторная загрузка в Настройках (тот же путь очистки + наполнение) доступна в любой момент после Знакомства.

Готово к использованию в тикете 12 (публикация релиза 0.6).
