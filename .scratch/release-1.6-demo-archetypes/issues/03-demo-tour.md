# Тикет 03 — 90-секундный демо-сценарий

Status: needs-triage
Blocked by: 01, 02
Type: task

## Вопрос

Добавить отдельный короткий показ возможностей на уже заполненном демо-профиле,
не ломая 15-шаговый приветственный тур релиза 1.2.

## Зафиксированное поведение

Сценарий не создаёт иллюзию работы на пустых данных: перед показом выбранный
профиль уже загружен. Демо показывает готовую историю, карточки агента,
прогноз и Синергию только там, где соответствующие релизы уже доступны.

## Testing Decisions

- Показ можно запустить и завершить без изменения данных профиля.
- Каждый шаг имеет существующий DOM-якорь или корректно пропускается с объяснением.
- 15-шаговый тур остаётся доступен отдельной командой.
- При `prefers-reduced-motion` сценарий не зависит от анимаций и звука.
