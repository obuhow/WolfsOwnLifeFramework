# Тикет 02 — Честная перезагрузка архетипа

Status: needs-triage
Blocked by: 01
Type: task

## Вопрос

Сделать переключение архетипа явной операцией с подтверждением потери данных.

## Что сделать

- перед `reloadProfile` показать, что текущие данные будут удалены;
- не выполнять purge при отмене, закрытии диалога или ошибке валидации;
- использовать существующий `UserPurgeService` и единый путь загрузки профиля;
- после успешной загрузки обновить все зависимые экраны и активное имя профиля;
- при ошибке вернуть понятный результат и не показывать частично загруженный профиль.

## Testing Decisions

- Отмена не вызывает purge и не меняет текущий профиль.
- Подтверждение очищает старый набор и загружает выбранный профиль.
- Повторный reload не оставляет данные предыдущего профиля.
- Ошибка загрузки видима пользователю и не выдаётся за успешное переключение.
