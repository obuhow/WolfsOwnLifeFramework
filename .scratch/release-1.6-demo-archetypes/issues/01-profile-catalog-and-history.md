# Тикет 01 — Каталог архетипов и готовая история

Status: needs-triage
Blocked by:
Type: task

## Вопрос

Подготовить три демо-профиля с непустой, согласованной историей и зафиксировать
контракт их отображаемых имён.

## Решение

Существующий slug `worker-class` сохраняется. Его display name меняется на
«Инженер на разгоне»; ссылки, JSON-ключи и `KNOWN_SLUGS` не мигрируются. Для
остальных профилей сохраняются действующие slug, если они уже используются кодом.

## Что сделать

- проверить полный набор `DemoProfile` для каждого профиля;
- наполнить историю Проектами, Делами, Записями времени, Целями, Заметками,
  Идеями и Синергиями там, где это поддерживается генератором;
- добавить данные, необходимые 90-секундному сценарию;
- исключить из фикстур обещания денег, внешних новостей и несуществующих таймеров;
- покрыть генератор тестом на имена, slug и минимальный набор сущностей.

## Testing Decisions

- Все три известных slug загружаются без ошибки.
- `worker-class` остаётся валидным входным slug, но отображается как
  «Инженер на разгоне».
- Профиль после генерации содержит непустую историю минимум в каждом модуле,
  который использует демо-сценарий.
- Повторный вызов генерации не создаёт дубли внутри одной загрузки.
