# Раздел Документация: Манифест, Сценарии использования, Технические инструкции

Status: open
Blocked by:

## Question

Реализовать раздел `/docs` внутри приложения по решениям тикетов «Манифест WOLF: правда о реализации» и «Раздел Документация: структура и Сценарии использования» карты `.scratch/wayfinder-releases-05-07/map.md`.

## Что сделать

1. Создать три Vue-компонента: `ManifestoView.vue`, `ScenariosView.vue`, `SelfHostingView.vue` под общим маршрутом `/docs` (подмаршруты `/docs/manifesto`, `/docs/scenarios`, `/docs/self-hosting`). Захардкоженный контент, не markdown-файлы и не записи в БД.
2. `/docs` и все три подмаршрута исключить из auth guard роутера — доступны неаутентифицированному посетителю.
3. **Манифест WOLF** — 5 из 6 принципов, каждый как «Принцип + Реализация + конкретный пример из жизни» (текст принципов и урезанные формулировки — см. `## Итоговый список для публикации в 0.5` тикета «Манифест WOLF: правда о реализации»). После пятого принципа — пометка про отложенный шестой без даты обещания. Заголовок раздела «Манифест WOLF» (не «Siberian Wolf»). Тон местами от первого лица — не переписывать.
4. **Сценарии использования** — истории трёх персонажей (Рабочий класс / Мудрый фрилансер / Свободный художник) в текстовой форме, тот же персонаж, что демо-профили тикета «Содержание трёх демо-профилей» (данные для загрузки — релиз 0.6, здесь только текст-повествование). Оглавление + якорные ссылки.
5. **Технические инструкции** — docker compose, требования к серверу, шаги развёртывания по выводам research-тикета «Правовая модель самохостинга: 152-ФЗ и трансграничная передача». Обязательная явная оговорка: закрытая инвайт-модель — разумная, но не подтверждённая практикой РКН трактовка «личных и семейных нужд»; риски локализации БД при расширении круга пользователей. Код-блоки без цветной подсветки синтаксиса (тихий контракт).
6. Визуальный контракт: узкая колонка ~680–720px, типографика тихого регистра 0.3 — графитовые чернила, тонкие нейтральные линейки, без акцентных цветов, без карточек с тенями, без прогресс-баров.
7. Пункт меню «Документация» (см. тикет 01) ведёт на `/docs`.

## Testing Decisions

- Открыть `/docs`, `/docs/manifesto`, `/docs/scenarios`, `/docs/self-hosting` в приватном окне без токена — все рендерятся, ни один не редиректит на `/login`.
- Инспекция DOM: ширина текстовой колонки 680–720px через `getBoundingClientRect()`, отсутствие акцентных цветов/теней/прогресс-баров.
- Проверить, что Манифест показывает ровно 5 принципов с примерами и пометку про шестой.
- Гейт: сборка `web` → пересоздание контейнера → сверка хэшей с `web/dist` → аутентификация в браузере → инспекция DOM.

## Out of Scope

Английская версия. Полнотекстовый поиск. Слияние с `docs-site`. Демо-профили как загружаемые данные (релиз 0.6). Шестой пункт Манифеста (ждёт тикета 0.4-07).
