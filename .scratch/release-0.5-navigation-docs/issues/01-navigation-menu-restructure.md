# Навигация: новая структура меню, переименования, редиректы

Status: open
Blocked by:

## Question

Реализовать новую структуру меню верхнего уровня по решениям тикета «Полная структура меню и судьба переименований» карты `.scratch/wayfinder-releases-05-07/map.md`.

## Что сделать

1. Перестроить `App.vue` (и связанную конфигурацию роутера в `main.js`) на шесть пунктов верхнего уровня: Утренний обход · Ежедневник · Управление делами · Управление потоком · Настройки · Документация (последний — заглушка/ссылка на маршрут `/docs`, реализуемый тикетом 02).
2. Ввести три подгруппы внутри «Управления делами»: Планирование (Дорожная карта, План нагрузки — якорь `#load-plan` на той же странице, Бэклог), Сущности (Проекты, Рутины, Дела, Банк идей), Аналитика (Статистика, Чек-лист).
3. Объединить `TodayView.vue` и `CalendarView.vue` (недельный/месячный вид, сейчас на `/calendar` и `/calendar/month`) под общим пунктом «Ежедневник» с вкладками Сегодня/Неделя/Месяц. Клик по пункту меню открывает `/calendar` (Неделя) по умолчанию. Каждая вкладка сохраняет собственный текущий URL — новых маршрутов не создаётся.
4. Переименовать четыре экрана — везде (заголовок компонента, пункт меню, все внутренние `router-link` и текстовые ссылки):
   - Диаграмма Ганта → Дорожная карта. `PlanningView.vue` переезжает с `/planning` на `/roadmap`; `/gantt` и `/planning` становятся редиректами 302 на `/roadmap`.
   - Кривая нагрузки → План нагрузки. **Не отдельный маршрут** — переименовать заголовок секции «Кривые нагрузки» внутри `PlanningView.vue` (та же страница, что Дорожная карта); пункт подменю — якорная ссылка `/roadmap#load-plan`. Не путать с одноимённым полем в `RoutinesView.vue` (настройка Рутины) — то поле не переименовывается.
   - Сферы жизни → Диаграмма компетенций. `SpheresView.vue` переезжает с `/spheres` на `/competency`; `/spheres` и `/synergy` (`SynergyView.vue`) становятся редиректами 302 на `/competency`, содержимое `SynergyView.vue` консолидируется как секция внутри `SpheresView.vue`.
   - Заметки / LLM Wiki → Личная база знаний. `PlaceholderView.vue` (маршрут `/notes`, `meta.title: 'Заметки / LLM Wiki'`) переезжает на `/knowledge`, `meta.title` обновляется; `/notes` становится редиректом 302 на `/knowledge`.
5. Добавить редиректы 302 в конфигурации роутера: `/gantt → /roadmap`, `/planning → /roadmap`, `/spheres → /competency`, `/synergy → /competency`, `/notes → /knowledge`. (`/week → /calendar` уже существует, не трогать.)
6. Обновить `CONTEXT.md`: добавить актуальные публичные имена к записям «Планирование (страница)» и «Календарь (страница)», пометить «Сферы жизни» устаревшим в пользу «Диаграмма компетенций» без удаления исторической записи.
7. **Обязательная проверка перед коммитом** (см. `wolf-life-os` skill, `references/navigation-ia-rewrite-safety.md`): сравнить полный список маршрутов `main.js` с набором ссылок в новом `App.vue` NAV — ни один маршрут с живым компонентом не должен потерять точку входа. Явные исключения (например `/admin/invites`, доступный только из `SettingsView.vue`, не из верхнего меню — это нормально и было так до этого релиза) — фиксировать явно, не молчаливым выпадением. Использовать скрипт-проверку из reference файла.

## Testing Decisions

- Ручной обход всех шести пунктов и трёх подгрупп «Управления делами» — маршрут открывается, заголовок совпадает с новым именем.
- Прямой заход на `/gantt`, `/spheres` в браузере — 302 на новый маршрут.
- `grep -r` по `web/src` на старые имена вне `CONTEXT.md` — ноль совпадений в активном UI-тексте.
- Гейт: сборка `web` → пересоздание контейнера → сверка хэшей с `web/dist` → аутентификация в браузере → инспекция DOM (пункты меню, заголовки, редиректы).

## Out of Scope

Раздел `/docs` (тикет 02). Тур/coach marks (релиз 0.6). Изменение домена/API — переименования затрагивают только UI-слой.
