# Финальный выбор и очистка профиля

Status: open
Blocked by: 03

## Question

Реализовать выбор «Оставить / Очистить» и точечную очистку данных профиля по решениям тикета «Механика Знакомства» карты `.scratch/wayfinder-releases-05-07/map.md`.

## Что сделать

1. Новый компонент `OnboardingFinalChoice.vue`. Две текстовые кнопки-действия без подтверждающего второго диалога: «Оставить предзаполненный профиль» и «Очистить профиль».
2. «Оставить» → `POST /api/v1/onboarding/complete` (существующий эндпоинт 0.4-08, `onboarding_completed_at = now()`) → редирект на `/calendar`.
3. «Очистить» → расширить `UserPurgeService` новым методом `purgeProfileData(User user)`: точечное удаление Проектов, Дел, Записей времени, Целей, Идей, Заметок текущего пользователя (не сам аккаунт, не через `ON DELETE CASCADE` пользователя). Не удалять: Области жизни, 9 Сфер (справочник). Сбросить `availableWeeklyHours` на системный дефолт.
4. После `purgeProfileData` → редирект на `/onboarding` (существующий мастер 0.4-08 — Проект → Цель → Норма, без изменений его кода) → по завершении мастера `onboarding_completed_at` проставляется как обычно → `/today`.

## Testing Decisions

- `ProfilePurgeIT`: после `purgeProfileData` — ноль Проектов/Дел/Записей времени/Целей/Идей/Заметок этого пользователя; Области жизни и 9 Сфер целы; норма — дефолт; ноль осиротевших строк в дочерних таблицах (Синергия, зависимости Проектов, недельные планы).
- Браузерная проверка ветки «Оставить»: данные профиля видны после редиректа на `/calendar`.
- Браузерная проверка ветки «Очистить»: экраны Проектов/Дел/Целей пусты, мастер 0.4-08 запускается, после его завершения «Сегодня» показывает остаток нормы по только что введённым пользователем данным.
- Гейт: сборка → пересоздание контейнера → сверка хэшей с `web/dist` → аутентификация в браузере → инспекция DOM.

## Out of Scope

Сам мастер 0.4-08 — не переписывается. Повторная загрузка из Настроек (тикет 05, использует тот же `purgeProfileData`, но другой вызывающий поток).
