# Тур Знакомства: ведущие подсказки по шести пунктам меню

Status: open
Blocked by: 02
Depends on: release-0.5-navigation-docs (утверждённая структура меню и DOM-цели тура)

## Question

Реализовать ведущий тур с подсветкой-вырезом по решениям тикета «Механика Знакомства: тур, финальный выбор, повторная загрузка» карты `.scratch/wayfinder-releases-05-07/map.md`.

## Что сделать

1. Новый компонент `OnboardingTour.vue`, монтируется поверх `App.vue` после релиза 0.5. Добавить `data-tour-target` атрибуты на шесть пунктов верхнего уровня NAV (Утренний обход · Ежедневник · Управление делами · Управление потоком · Настройки · Документация) в `App.vue`, если их там ещё нет.
2. Механика: модальное затемнение с вырезом под активный элемент + текстовая подсказка рядом. Блокирует клики вне цели текущего шага. 6–7 шагов, один клик = один пункт верхнего уровня. Без прогресс-бара («шаг 3 из 7»).
3. Выход в любой момент — явная кнопка «Пропустить»/«Завершить». Прерывание не требует специального состояния — сразу переход к Финальному выбору (тикет 04).
4. Состояние тура не сохраняется в БД — при следующем ручном запуске (см. Настройки, тикет 05) начинается заново.
5. Мобильное поведение: та же ведущая механика через drawer — подсказка инструктирует открыть меню, тур ждёт открытия drawer, затем клика по нужному пункту внутри него.
6. Показ тура управляется `onboarding_completed_at` (существующее поле из 0.4-01) — не создавать отдельный признак.

## Testing Decisions

- Ручной обход всех 6–7 шагов на десктопе — подсветка следует за кликами, интерфейс вне цели заблокирован.
- Мобильный обход — тур открывает drawer по подсказке, засчитывает клик внутри него.
- Прерывание на любом шаге (2, 4, 6) — сразу попадает на Финальный выбор.
- Инспекция DOM: нет прогресс-бара, нет цветных индикаторов (тихий контракт 0.3).
- Гейт: сборка → пересоздание контейнера → сверка хэшей с `web/dist` → аутентификация в браузере → инспекция DOM.

## Out of Scope

Финальный выбор и очистка (тикет 04). Изменения самой структуры меню — тур только читает `data-tour-target`, не меняет NAV.
