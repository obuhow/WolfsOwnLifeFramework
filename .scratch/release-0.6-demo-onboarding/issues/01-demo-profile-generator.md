# Расширение DemoFixtureGenerator: декларативные профили + три JSON-файла

Status: open
Blocked by:

## Question

Реализовать многопрофильную генерацию демо-данных по решениям тикета «Содержание трёх демо-профилей» карты `.scratch/wayfinder-releases-05-07/map.md`.

## Что сделать

1. Ввести модель `DemoProfile` (Java record/класс), десериализуемую из JSON по структуре эталона тикета «Содержание трёх демо-профилей» (поля: `slug`, `displayName`, `weeklyHoursNorm`, `timezone`, `areas`, `projects`, `goals`, `delosSample`, `routines`, `timeEntriesHistoryDays`, `ideas`, `notes`, `synergy`).
2. Расширить `DemoFixtureGenerator.populate(User user)` до `populate(User user, DemoProfile profile)`. Сохранить существующую проверку идемпотентности (отказ, если у пользователя уже есть данные). Все даты профиля — смещения (`startOffsetDays`, `dueOffsetDays`) от `LocalDate.now(zone)` в момент вызова, не абсолютные значения.
3. Создать три файла `assets/profiles/worker-class.json`, `assets/profiles/wise-freelancer.json`, `assets/profiles/free-artist.json` в репозитории WOLF. Первый — по эталону из тикета карты 05-07 дословно. Второй и третий — дописать по параметрам того же тикета (норма часов, число проектов, тон, содержание Банка идей) до полного набора Дел/Заметок/Проектов/Целей/Рутин, соответствующего структуре первого.
4. `POST /api/v1/onboarding/load-profile` — принимает `{ "slug": "worker-class" }`, десериализует соответствующий JSON, вызывает `populate(user, profile)`.
5. Обязательный охват: каждый пункт меню, утверждённого в релизе 0.5, получает непустое содержимое от любого из трёх профилей — Проекты, Дела, Записи времени (30 дней истории), Цели, Идеи, Синергия/Диаграмма компетенций, Рутины (через `RecurrenceService`), Заметки (минимум одна с `fromAgent: true`/автором «Агент»).

## Testing Decisions

- `DemoProfileLoadIT`: загрузка каждого из трёх профилей на чистом пользователе — все перечисленные сущности непустые.
- Тест дата-сдвига: запуск с разными «текущими» датами (мокнутый `Clock`/переданная `LocalDate`) — результат одинаково свежий, сегодняшний день истории заполнен частично.
- Повторный вызов `populate` на уже заполненном пользователе — отказ (сохранённая идемпотентность), не тихая перезапись.

## Out of Scope

Экран выбора профиля (тикет 02). Очистка/повторная загрузка (тикет 03). Полное дословное содержание Дел для второго и третьего профиля сверх параметров тикета карты 05-07 — минимально необходимый набор для покрытия меню, не более.
