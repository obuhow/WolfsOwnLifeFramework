Для каждого Проекта виден factual `x / y ч` — выполненные часы в ISO‑неделе / план текущей недели — и связанные Дела. ## Answer

Экран «Сегодня» переведён в вариант 1a. Слева — 15‑минутный реестр с осью времени 64px и строками 26px (hour-линии `--rule`, quarter-hour `--subrule`, tabular-время, graphite-маркер текущего интервала); planned — нейтральный `#F7F8FA`, DONE — `--done-surface`, «Сон» без фиолетового; клики по краю ±15м / по середине разрез и модальное создание сохранены (поведение 0.1 не тронуто). Реестр владеет левой колонкой на всю высоту, отделён 1px правилом; asides идут в правой колонке 268px и стекаются под реестром на mobile (≤900px).

Справа «Бэклог недели» сгруппирован по Проектам: заголовок Проекта + `x / y ч`, где `x` — выполненный факт текущей ISO‑недели, `y` — план недели; оба значения берутся из реального агрегата Gantt (`GET /api/v1/gantt?from=<monday>&weeks=1`, `cells[].factHours/planHours`), а не считаются из видимой страницы. Отсутствующий план рендерится как `—`. Дела без Проекта — в отдельной группе «Без проекта» без `x / y ч`. Удалена запрещённая контрактом панель «План и факт недели» со шкалой прогресса/процентом.

Проверка: `npm run build` OK; `docker compose build web` + пересоздание web-контейнера; served asset-хэши совпадают с `web/dist` (`index-DUz4EA7m.js` / `index-ewaKLvkz.css`); в отданном бандле подтверждены группировка бэклога и группа «Без проекта». Авторизованный browser/DOM-замер геометрии реестра не выполнен (remote debugging в Chrome не включён) — геометрия соответствует CSS-контракту (64px/26px/shared columns), но не измерена в живом DOM; пользователю предложено проверить визуально.
