# 03 — Сегодня: 15-минутный реестр и проектный бэклог недели

**What to build:** Экран «Сегодня» становится вариантом 1a: слева точный 15‑минутный реестр дня, справа бэклог текущей недели, сгруппированный по Проектам. Для каждого Проекта виден factual `x / y ч` — выполненные часы в ISO‑неделе / план текущей недели — и связанные Дела. Поведение 0.1 по размещению, подтверждению, ночным часам и TimeEntry сохраняется.

**Blocked by:** 01 — Глобальная дизайн-система и базовые контролы; 02 — Навигационный shell: desktop top-bar и mobile drawer.

**Status:** ready-for-agent

- [ ] Today показывает информационный заголовок с датой, предыдущим/следующим днём, управлением ночными часами и текстовыми действиями без hero/карточек.
- [ ] Левая сетка имеет 64px time axis, 26px quarter-hour rows, отдельные hour/subrule линии, tabular‑время, корректное отображение интервалов и graphite‑маркер текущего времени.
- [ ] Planned записи имеют нейтральное оформление, DONE — бледно‑зелёное; Сон не получает фиолетовый или тревожный статус; клики и модальное создание работают как раньше.
- [ ] Справа отображается «Бэклог недели», сгруппированный по Проектам, с заголовком Проекта и `x / y ч`; `y` отсутствующего плана отображается как `—`, а Дела без связи попадают в отдельную группу «Без проекта».
- [ ] Бэклог получает свои fact/plan значения от реальных данных/API, не рассчитывает фиктивные числа из видимой страницы и не показывает шкалу прогресса/оценку.
- [ ] На mobile реестр остаётся первичным, а бэклог следует ниже него в корректном reading order.
- [ ] После deploy выполнена авторизованная browser/DOM‑проверка сетки, правого бэклога, выбранного completed state и hard refresh.
