# 04 — Календарь: неделя в геометрии 15-минутного реестра

**What to build:** «Календарь → Неделя» получает тот же язык 1a, что и Today: общий 15‑минутный временной реестр, семь точно выровненных колонок дней и соседний проектный бэклог недели. Страница остаётся полноценным редактором временных записей и не сжимает дни до нечитаемого состояния на mobile.

**Blocked by:** 01 — Глобальная дизайн-система и базовые контролы; 02 — Навигационный shell: desktop top-bar и mobile drawer; 03 — Сегодня: 15-минутный реестр и проектный бэклог недели.

**Status:** ready-for-agent

- [ ] Маршрут и пользовательский заголовок используют «Календарь → Неделя», сохраняя все текущие 0.1 операции: создание, очистку, подтверждение, ночные часы и быстрый выбор Дела.
- [ ] Временная ось, header дней и body используют один явный CSS Grid coordinate system; часы, четверти часа и интервальные блоки визуально согласованы.
- [ ] Каждый день имеет понятный заголовок с днём недели и датой; запись сохраняет начальную/конечную границу и status treatment из Today.
- [ ] Справа показывается тот же сгруппированный недельный бэклог с Project `x / y ч`, включая «Без проекта».
- [ ] На mobile недельная таблица лежит в подписанном горизонтальном scroll‑контейнере с достижимой осью времени; бэклог идёт ниже сетки.
- [ ] После deploy авторизованный DOM‑probe показывает для заголовков и первой строки дня дельту left/width не более 1px; проверка зафиксирована в результате тикета.
