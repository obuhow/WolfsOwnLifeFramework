## Answer

«Календарь → Неделя» (`WeekView.vue`) переведён в язык 1a. Сетка уже строится на едином явном CSS Grid: строка заголовков дней (`gridRow: 1`) и все ячейки тела используют одни и те же колонки `3.25rem repeat(--day-cols, minmax(5.5rem, 1fr))` и общий ряд-трек, поэтому заголовок дня и первая ячейка того же дня выровнены по построению (не auto-placement). Цвета выведены на токены: тёплые бежевые фоны углов/заголовков/оси времени/ячеек заменены на `--wolf-surface`/`--wolf-rule`/`--wolf-subrule`, planned `#F7F8FA`, DONE `--done-surface`, ночь без фиолетового, `is-today` — нейтральный `--wolf-hover` + graphite подчёркивание. Все операции 0.1 (grid-click, снятие, подтверждение, «Подтвердить все», ночь, быстрое создание Дела) сохранены.

Правый aside заменён на тот же сгруппированный по Проектам «Бэклог недели» из тикета 03: заголовок Проекта + `x / y ч` (факт/план недели из `GET /api/v1/gantt?from=<monday>&weeks=1`), отсутствующий план — `—`, Дела без Проекта — в «Без проекта». Бэклог грузится/обновляется вместе с неделей и после мутаций. Горизонтальная сетка обёрнута в подписанный scroll-регион (`role="region"`, aria-label, `tabindex=0`); на ≤1000px aside уходит под сетку.

Проверка: `npm run build` OK; `docker compose build web` + пересоздание web-контейнера; served asset-хэши совпадают с `web/dist` (`index-BJyHy9eF.js` / `index-Dn3IdUB6.css`); в бандле подтверждены группированный бэклог и подписанный scroll-регион. Живой DOM-замер геометрии не выполнен (remote debugging в Chrome не включён).
