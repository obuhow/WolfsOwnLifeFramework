# 02 — Навигационный shell: desktop top-bar и mobile drawer

**What to build:** Авторизованный пользователь получает утверждённую навигацию: компактную верхнюю панель на desktop и focus‑managed drawer на mobile. «Сегодня» — прямая ссылка; остальные разделы раскрывают согласованные подменю. Старые адреса недели и Ганта продолжают приводить к новым пользовательским разделам через совместимые редиректы.

**Blocked by:** 01 — Глобальная дизайн-система и базовые контролы.

**Status:** ready-for-agent

- [ ] На desktop видны WOLF, прямой пункт «Сегодня», группы «Календарь», «Планирование», «Управление проектами», «Управление потоком», прямой пункт «Настройки», пользователь и выход.
- [ ] Группы открываются по click/keyboard, используют корректные `aria-expanded`, закрываются по Escape и click-away, а активный дочерний маршрут помечает также родительскую группу.
- [ ] «Календарь» содержит «Неделя», «Месяц»; «Планирование» — «Диаграмма Ганта», «Бэклог»; «Управление проектами» — «Области жизни», «Проекты», «Дела», «Банк идей»; «Управление потоком» — «Цели», «Сферы жизни», «Синергия», «Утренний обход», «Заметки / LLM Wiki», «Отчёт „Чек-лист“».
- [ ] На ширине mobile верхняя навигация заменяется drawer: фокус удерживается в нём, возвращается к trigger после закрытия, текущая группа раскрыта, выбор маршрута закрывает drawer.
- [ ] Сегодня не имеет подменю; будущий Канбан не показывается как фальшивая или disabled-ссылка.
- [ ] `#/week` и `#/gantt` сохраняют рабочую совместимость через редиректы к названиям/маршрутам Release 0.2.
