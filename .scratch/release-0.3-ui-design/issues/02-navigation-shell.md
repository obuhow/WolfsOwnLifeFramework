# 02 — Навигационный shell: desktop top-bar и mobile drawer

**What to build:** Авторизованный пользователь получает утверждённую навигацию: компактную верхнюю панель на desktop и focus‑managed drawer на mobile. «Сегодня» — прямая ссылка; остальные разделы раскрывают согласованные подменю. Старые адреса недели и Ганта продолжают приводить к новым пользовательским разделам через совместимые редиректы.

**Blocked by:** 01 — Глобальная дизайн-система и базовые контролы.

## Answer

Переписан навигационный shell (`web/src/App.vue`) под утверждённую IA Release 0.3: компактный desktop top-bar с прямыми пунктами «Сегодня»/«Настройки» и раскрывающимися группами «Календарь», «Планирование», «Управление проектами», «Управление потоком». Группы открываются по click и с клавиатуры (`aria-expanded`, Enter/Space, Escape, click-away), активный дочерний маршрут подсвечивает и родителя. На mobile (≤768px) top-bar заменяется focus-trapped drawer с раскрывающимися группами (текущая раскрыта), закрытием по Escape/overlay/выбору маршрута и возвратом фокуса на trigger; блокировка скролла фона. Канбан не рендерится как fake/disabled. Добавлены недостающие маршруты (`/calendar/month`, `/planning/backlog`, `/spheres`, `/synergy`, `/notes`) как `PlaceholderView` — контракт формализуется тикетами 07–09. Совместимость `#/week → /calendar` и `#/gantt → /planning` сохранена. Проверка: `npm run build` OK; `docker compose build web` + пересоздание web-контейнера; served asset-хэши совпадают с `web/dist` (`index-C-Ez0JQH.js` / `index-DwsSZtqo.css`); API health `UP`; в отданном бандле подтверждены новые группы IA и редирект-маршруты.
