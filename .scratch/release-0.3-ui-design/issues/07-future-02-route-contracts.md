## Answer

`PlaceholderView.vue` превращён из одной общей строки в **route-contract каркас**: он рендерит утверждённый заголовок, анатомию секций, перечень полей и фактический empty-state из `route.meta`, при этом **не делает ни одного запроса к API** и не показывает расчётных значений. Каждый каркас явно называет владеющий функциональный тикет («данные появятся в тикете 08/09»), поэтому 0.2 может наполнить маршруты, не переизобретая визуальный контракт.

Наполнены каркасы пяти будущих маршрутов:
- **`/calendar/month`** — секция «Сетка месяца» (семь колонок Пн–Вс, номер дня, компактные подписи, явная оговорка «не редактор слотов») + два aside: «Бэклог недели» и «Бэклог месяца».
- **`/planning/backlog`** — секции «Период» (охват Неделя/Месяц, навигация) и «Группы по Проектам» (тот же групповой реестр с `x / y ч`, «Без проекта», действие «Перенести в неделю»).
- **`/spheres`** — «Справочник сфер» (название + краткое описание; сферы как справочные данные, а не оценка).
- **`/synergy`** — «Матрица синергии» (субъект, Сфера, знак `+ / 0 / −`, описание; явно без красного кодирования отрицательного влияния).
- **`/notes`** — «Поиск и фильтры», «Хронологический реестр» (контекст источника, автор, отметка времени, теги, аудио отдельной строкой вложения; материал агента — подпись + тонкое левое правило, не яркий блок) и «Сводка» (явное текстовое действие, помеченная секция, не чат-пузырь).

Остальные destinations из согласованной IA уже имеют собственные компоненты (Цели, Банк идей, Утренний обход, Отчёт «Чек-лист»), поэтому каркасы им не требуются. Проверено статически: все 16 целей навигации из `App.vue` имеют маршрут в `main.js` — 404 и фальшивых disabled-пунктов нет. Каркас использует те же токены `--wolf-*`, правила-разделители и 268px aside, что и рабочие экраны; на ≤900px aside уходит под основную колонку.

Проверка: `npm run build` OK; `docker compose build web` + пересоздание контейнера; served-хэши совпадают с `web/dist` (`index-Dy2VAMLg.js` / `index-DGPJd5SP.css`); в бандле подтверждены `Матрица синергии`, `Хронологический реестр`, `Группы по Проектам`, `Бэклог месяца`, в CSS — `scaffold-aside`, `scaffold-fields`. Живая browser-проверка не выполнена по решению пользователя.
