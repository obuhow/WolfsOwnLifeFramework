## Answer

Все административные экраны приведены к flat-register языку. Ключевое поведенческое изменение — **destructive actions больше не используют нативный `confirm()`**: добавлен общий компонент `ConfirmInline.vue`, который «взводит» действие на месте и требует второго явного текстового подтверждения («Удалить» → «Удалить X?» + «Да, удалить» / «Отмена»), с автофокусом на подтверждении и Escape для отмены. Он подключён во всех шести местах удаления: Области жизни, Проекты, Дела, Project detail, Delo detail, Заметки. Красные иконочные кнопки (`style="color: #8a3a3a"`, SVG-корзины) удалены.

CSV-импорт стал ruled expandable section: кнопка-триггер с `aria-expanded`/`aria-controls`, раскрывающаяся секция с верхним/нижним правилом, и **полный schema hint** вместо однострочного — `title,date,startAt,endAt,description,executionMode,projects,lifeArea` плюс построчная расшифровка (форматы `YYYY-MM-DD`, `HH:mm` по 15-минутной сетке, значения `executionMode`, разделитель Проектов `|`, правило про существующую Область жизни) и примечание, что файл проверяется целиком и при ошибке ничего не импортируется. Серверная row-level ошибка по-прежнему читается text-first (`res.text()` → попытка JSON) и показывается как текст.

Настройки разбиты на семантические `<fieldset>` с `<legend>`: «Время и границы суток» (часовой пояс, конец дня, авто-Сон, ночные часы) и «Учёт часов и нагрузка» (режим учёта, режим фиксации, доступные часы) — с правилом-подчёркиванием и сохранёнными фактическими help-текстами. Реестры, детали, Login и общие контролы уже используют плоские токены из тикета 01 (`.card`, `.btn`, `.input` — без радиусов и теней), поэтому доменное поведение не менялось.

**Инцидент при реализации:** пакетная вставка импортов через полную перезапись файлов записала обратно редакцию `read_file` — строка `Authorization: `Bearer ${token}`` в 5 файлах превратилась в `Authorization: *** ${token}``, и сборка упала. Исправлено точечной заменой во всех 5 файлах; проверено `grep` (маркеров редакции не осталось) и `git diff --stat` (в диффе только целевые изменения). Это подтверждает пункт скилла «никогда не записывать вывод `read_file` обратно дословно».

Проверка: `npm run build` OK (67 модулей, включая `ConfirmInline`); `docker compose build web` + пересоздание контейнера; API `{"status":"UP"}`; served-хэши совпадают с `web/dist` (`index-B_Ns4z8h.js` / `index-BWYLQKKx.css`); в бандле подтверждены `Да, удалить`, `Точно удалить`, `Скрыть импорт CSV`, `lifeArea`, `Учёт часов и нагрузка`, в CSS — `confirm-inline`, `csv-schema`, `settings-fieldset`.
