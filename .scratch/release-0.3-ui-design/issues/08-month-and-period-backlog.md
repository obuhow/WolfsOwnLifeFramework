# 08 — Календарь: Месяц и Планирование: Бэклог

**What to build:** После готовности соответствующей функциональности 0.2 пользователь получает полноценные «Календарь → Месяц» и «Планирование → Бэклог»: обзорную месячную сетку, period backlog недели/месяца, группировку по Проектам и явные действия переноса без автоматического планирования.

**Blocked by:** 04 — Календарь: неделя в геометрии 15-минутного реестра; 07 — Контрактные маршруты будущего Release 0.2; соответствующие функциональные тикеты Release 0.2 для месячного Calendar и period Backlog.

**Status:** ready-for-agent

- [ ] Месяц получает реальную API‑агрегацию: семь day columns, 5–6 week rows, out-of-month days, компактные factual time-entry labels и переход в нужный день/неделю.
- [ ] Month companion panel показывает реальные weekly и monthly backlog groups по Проектам с `x / y ч`, не раскладывая элементы автоматически по слотам/неделям.
- [ ] Полноэкранный Бэклог поддерживает реальные scope `Неделя` / `Месяц`, period navigation, группировку, явный move-to-week и все правила отсутствующего plan (`—`).
- [ ] На mobile месячная сетка/бэклог имеют предусмотренный scroll/stacking behaviour; действия не становятся недостижимыми.
- [ ] Авторизованный browser smoke подтверждает, что Month и Backlog отображают реальные данные и не создают TimeEntry при просмотре/переключении scope.
