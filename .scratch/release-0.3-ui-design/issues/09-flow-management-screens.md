# 09 — Управление потоком: функциональные экраны Release 0.2

**What to build:** После готовности своих доменных API экраны Целей, Сфер жизни, Синергии, Банка идей, Утреннего обхода, Заметок / LLM Wiki и Отчёта «Чек-лист» получают реальные данные и действия, сохраняя тихий register‑контракт: факты и прогнозы без стриков, пушей, тревожных цветов, оценок или скрытой генерации сущностей.

**Blocked by:** 07 — Контрактные маршруты будущего Release 0.2; соответствующие функциональные тикеты Release 0.2 для Goals, Life Spheres/Synergy, Ideas, Notes/Agent/Morning Digest и Checklist Report.

**Status:** ready-for-agent

- [ ] Цели показывают реальный priority, weekly budget, current-week fact, metric и Project links; изменение бюджета остаётся нейтральной корректировкой без warning state.
- [ ] Сферы и Синергия показывают реальные subject/sphere/signed impact/description; положительное, нейтральное и отрицательное влияние остаётся текстово различимым без красного сигнала.
- [ ] Банк идей использует реальную category/state/synergy и явное «Взять в работу»; до promotion идея не получает ложные часы или TimeEntry.
- [ ] Утренний обход показывает реальные active Projects, latest user note, отдельно маркированный материал автора «Агент» и next Delos; отсутствуют push/badge/reminder patterns.
- [ ] Wiki поддерживает реальные search/filter/context/author/attachments/transcript/tags, а summary вызывается явным действием и отображается как labelled record, не chat UI.
- [ ] Отчёт чек-листа показывает фактические date-range records и switch marks, а дни без данных остаются нейтральными; нет streak, missed-day или guilt copy.
- [ ] Авторизованный browser smoke проверяет реальные API данные, mobile drawer/navigation, keyboard controls и pale-green done state без визуальных регрессий.
