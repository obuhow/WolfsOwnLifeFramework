## Answer

Экраны «Управление потоком» доведены до реальных данных, и попутно найдены и устранены **три нарушения тихого контракта**, которые оставались в коде с прошлых релизов.

**Новые экраны.** `/spheres` и `/synergy` перестали быть каркасами:
- **Сферы жизни** (`SpheresView.vue`) — ruled-реестр «название + краткое описание» на `GET/POST/PUT/DELETE /life-spheres`, с архивированием, фильтром «показывать архивные» и инлайн-подтверждением удаления. Сферы поданы как справочные данные, без какой-либо оценки пользователя.
- **Синергия** (`SynergyView.vue`) — реестр «субъект (Проект/Идея) × Сфера × влияние» на `/synergies` + `/life-spheres` + `/projects` + `/ideas`. Влияние показано **знаком и словом** (`+ поддерживает`, `0 нейтрально`, `− требует ресурса`), меняется селектом прямо в строке. Отрицательное влияние **не кодируется красным** и не подаётся как проблема — это факт распределения ресурса.

**Исправления контракта в существующих экранах:**
1. **Утренний обход** содержал **прогресс-бар с процентами** по целям (`Math.min(100, fact/budget*100)`) — прямое нарушение запрета на прогресс-бары и проценты. Заменён на нейтральную строку `x / y ч`.
2. Материал агента был залит `--wolf-done-surface` (бледно-зелёный зарезервирован **только** за выполненным фактом). Теперь это тонкое левое graphite-правило + подпись автора «Агент», как требует спека.
3. Заголовок «Утро» приведён к утверждённому «Утренний обход»; подпись автора — «Агент» / «Моя заметка» вместо «подложка агента».
4. **Цели** содержали красную краску ошибки `#8b3c35` — заменена на нейтральные чернила.
5. **Отчёт «Чек-лист»** переписан из карточек в хронологическую ruled-таблицу по дням: **бледно-зелёная заливка только у выполненных пунктов**, день без данных — нейтральная строка «Записей за этот день нет» (не «провал»), переключения показаны с отметкой времени без негативной рамки «отвлечение».

Цели, Банк идей и Заметки/LLM Wiki уже работали на реальных API (`/goals` с budget/metrics/fact/projects, `/ideas` с promote, `/notes` + `/notes` assistant) и контракту соответствуют — правки не потребовались, кроме пункта 4.

Проверка: `npm run build` OK; `docker compose build web` + пересоздание контейнера; served-хэши совпадают с `web/dist` (`index-C9M8f3C4.js` / `index-BoJDH2Bo.css`); маркеры `Утренний обход`, `требует ресурса`, `Добавить сферу`, `life-spheres`, `synergies`, `Записей за этот день нет` подтверждены в бандле.
