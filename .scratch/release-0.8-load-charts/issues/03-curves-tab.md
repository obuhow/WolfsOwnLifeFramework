# Вкладка «Кривые»: интерактивные ступенчатые кривые загрузки (вариант 3a)

Status: ready-for-agent
Blocked by: 01, 02

## Question

Реализовать вкладку «Кривые» — дорожка на проект со ступенчатой кривой часов в неделю на горизонте 18 месяцев, с перетаскиванием точек, добавлением и удалением, вертикальной риской прогнозного финиша и строкой суммарной загрузки снизу.

Референс поведения: `ref/WOLF - планирование (варианты).dc.html`, вариант `3a`. Читать `<script type="text/x-dc">` в конце файла как исполняемую спецификацию: `hoursAt()`, `startDrag`, `addPoint`, `dropPoint`, расчёт `segs` / `handles` / `load`. Переносить логику и геометрию, **не цвета и не пиксельные константы дорожки**.

## Что сделать

1. **Шкала месяцев** сверху: метки по кварталам горизонта, позиционирование процентами от ширины дорожки.
2. **Дорожка на проект.** Слева — название и подпись объёма («8 Дел · 145 ч», для `effortSource: ESTIMATED` — тонкая пометка «оценка»). В центре — дорожка с сегментами кривой. Справа — прогнозный финиш (`forecastByCurve`) и текстовая запись плана вида «16 ч/нед → 8 ч с 2-го мес.». Финиш `null` показывается как «не закрывается».
3. **Сегменты кривой:** заливка `--wolf-subrule`, верхняя граница 1.5px `--wolf-ink`, `pointer-events: none`. Сегмент с нулём часов — прозрачный.
4. **Ручки:** квадрат 9×9 `--wolf-ink`, активная при перетаскивании — `--wolf-focus`. Перетаскивание меняет часы (вертикаль, шаг 1 ч, диапазон 0–20) и месяц перехода (горизонталь). **Первая точка не двигается по горизонтали** (`cursor: ns-resize`) и не удаляется — как в референсе.
5. **Клик по пустому месту дорожки** добавляет точку в этом месяце с этими часами (только если `e.target === e.currentTarget`). **Двойной клик по точке** её убирает, кроме первой.
6. **Вертикальная риска прогнозного финиша** на дорожке — 1px `--wolf-muted`, `pointer-events: none`. При `forecastByCurve: null` риска не рисуется.
7. **Запись изменений** через общий хелпер тикета 02 (дебаунс 400 мс после `pointerup`, откат при ошибке):
   - перетащили или добавили точку → `PUT /api/v1/projects/{id}/load-curve` с `{ weekStart, hours }`;
   - убрали точку → `DELETE /api/v1/projects/{id}/load-curve/{entryId}`;
   - месяц переводится в понедельник соответствующей ISO-недели (`LoadCurveController` уже нормализует `weekStart`).
   Промежуточное состояние перетаскивания показывается локально сразу, интерфейс не ждёт ответа сервера.
8. **Строка суммарной загрузки** снизу: столбец на месяц горизонта из `monthlyLoad`, пунктирная линия нормы `--wolf-faint`, подпись «пунктир — 30 ч / нед». Месяц с `overLimit: true` — **штриховка, не красный цвет**. Над строкой — текст вида «Пик загрузки 34 ч/нед — перебор на 4 ч» либо «Пик загрузки 22 ч/нед из 30. В лимите.»
9. **Геометрия — одна CSS Grid координатная система** для шкалы месяцев, дорожек и строки суммарной загрузки:
   ```css
   .load-lanes, .load-lane-header, .load-total-row {
     display: grid;
     grid-template-columns: 14rem minmax(0, 1fr) 9rem;
   }
   ```
   Дорожка тянется по ширине контейнера; координаты при перетаскивании считаются от `getBoundingClientRect()` дорожки. Константа `LANE_W: 720` из референса **не переносится**.
10. **Клавиатура.** Ручки фокусируемые (`tabindex="0"`): ←/→ двигают месяц перехода, ↑/↓ меняют часы шагом 1, `Delete` убирает точку (кроме первой). Текстовая запись плана рядом с дорожкой служит доступным описанием кривой.
11. **Мобильный вид (≤700px).** Перетаскивание 9-пиксельной ручки пальцем честно не работает — на узком экране дорожка **только для чтения** (кривая видна, ручки скрыты), а точки редактируются компактной текстовой формой под дорожкой: список «с какого месяца — сколько часов», поля ввода, действие «убрать». Тот же API, другой способ ввода. Диаграмма не притворяется интерактивной там, где взаимодействие не работает.

## Testing Decisions

- Ручная приёмка записи: перетащить точку → перезагрузить страницу → точка на новом месте.
- Ручная приёмка дебаунса: одно перетаскивание через всю дорожку порождает один `PUT`, не поток запросов (вкладка Network).
- Ручная приёмка отката: offline в devtools → значение возвращается к серверному, показана строка ошибки.
- Добавление точки кликом и удаление двойным кликом отражаются в БД (`GET /projects/{id}/load-curve` после действия).
- Первая точка: горизонтальное перетаскивание не двигает её месяц, двойной клик её не удаляет.
- Геометрия (обязательный гейт): после деплоя — аутентификация, hard refresh, `/roadmap?chart=curves`, сверка `getBoundingClientRect()` заголовка шкалы месяцев с первой дорожкой и строкой суммарной загрузки; расхождения `left`/`width` ≤ 1px.
- Тихий контракт 0.3: при переборе нормы в DOM нет `red`/`#a33`/`--wolf-danger`, нет `role="alert"`, поля не блокируются.
- Мобильная проверка на 390px: ручки скрыты, видна текстовая форма точек, изменение через неё уходит на сервер.
- Клавиатура: `Tab` доходит до ручки, стрелки меняют значение, изменение уходит на сервер.
- Гейт визуального тикета: сборка → пересоздание контейнера → сверка хэшей ассетов → аутентификация → инспекция DOM.

## Out of Scope

Кривые для Рутин — `LoadCurveEntry` поддерживает `routine_id`, но дорожки рутин в этот релиз не входят; рутины участвуют только в суммарной загрузке. Автоматическое выравнивание перегруза — противоречит принципу ручной месячной коррекции.
