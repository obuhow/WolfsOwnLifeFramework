# Страница проекта: кнопка «Распределить время» и редактор кривой нагрузки

Status: resolved
Blocked by: 01, 03

## Question

На странице каждого проекта (включая подпроекты, открытые отдельно по `/projects/{id}`)
должна появиться кнопка «Распределить время». По ней открывается модальное окно с
редактором ступенчатой кривой нагрузки этого проекта — таким же, как дорожка на вкладке
«Кривые» диаграмм нагрузки (вариант 3a): перетаскивание ручки меняет часы и месяц
перехода, клик по пустому месту дорожки добавляет точку, двойной клик по точке убирает
(кроме первой), плюс мобильная текстовая форма на узком экране.

Бэкенд уже готов (тикет 03): `GET/PUT/DELETE /api/v1/projects/{id}/load-curve`
(`LoadCurveController` + `LoadCurveService` + `LoadCurveEntry`). Объём проекта —
поле `totalPlanHours` («План, часы») — уже редактируется в карточке проекта. Этот тикет
добавляет именно **кривую распределения** поверх общего объёма: «план 160 часов, первые
6 недель по 10 ч, дальше 20 недель по 5 ч».

## Что сделать

1. **Переиспользуемая дорожка `LoadCurveLane.vue`.** Вынести логику одной дорожки из
   `CurvesTab.vue` (перетаскивание ручки, клик-добавить, двойной клик-удалить, мобильная
   текстовая форма, запись через `useLoadChartWrite`) в отдельный компонент, который умеет
   работать **автономно** (без `inject('loadCharts')`): сам грузит
   `GET /projects/{id}/load-curve` и пишет через `useLoadChartWrite` с URL
   `PUT /projects/{id}/load-curve`. Пропсы: `projectId`, `title`, `startMonday`,
   `horizonMonths`, опционально `curve` (если дан кривой снаружи).
2. **Рефакторинг `CurvesTab.vue`:** тело дорожки заменить на `<LoadCurveLane>` для каждого
   проекта (без смены контракта вкладки — геометрия, взаимодействие, запись те же).
   Суммарная строка и шкала месяцев остаются в `CurvesTab`.
3. **`ProjectDetailView.vue`:** на карточке проекта — кнопка «Распределить время»
   (рядом с «Изменить»). По клику — модальное окно (`role="dialog"`, доступное с
   клавиатуры, закрытие по Esc/клику вне) с одним `<LoadCurveLane>` для этого проекта.
   Заголовок модалки — название проекта + объём (`totalPlanHours`). Под дорожкой —
   текстовая подпись плана («16 ч/нед → 8 ч с 2-го мес.») и, при ошибке PUT, строка
   ошибки (тихий контракт 0.3: `--wolf-ink`, без `role="alert"`/цвета).
4. **Доступность:** ручки фокусируемы (`tabindex`), стрелки ←/→ двигают месяц, ↑/↓ часы,
   `Delete` удаляет; модалка ловит `Esc`. Кнопка «Распределить время» — настоящий
   `<button>` с `aria-label`.
5. **Тихий контракт 0.3** — те же токены `--wolf-*`, что в `CurvesTab`; без сигнальных
   цветов, прогресс-баров, `role="alert"`.

## Testing Decisions

- Кнопка «Распределить время» открывает модалку с дорожкой проекта; дорожка показывает
  текущую кривую (или одну точку 0 ч, если кривой нет).
- Перетащить ручку / кликнуть дорожку / двойной клик по точке → изменение видно сразу,
  через ~400 мс уходит `PUT /projects/{id}/load-curve`; перезагрузка страницы показывает
  сохранённую кривую.
- Закрытие модалки по Esc и по клику вне — дорожка на вкладке «Кривые» отражает те же
  точки (общий бэкенд).
- Мобильная ширина 390px: в модалке — текстовая форма точек, ручки скрыты.
- Клавиатура: `Tab` доходит до ручки, стрелки меняют значение, `Delete` убирает точку.
- Геометрия (для метрики проекта): `getBoundingClientRect()` дорожки и сегментов совпадает
  со вкладкой «Кривые» (та же логика позиционирования).
- Тихий контракт 0.3: инспекция DOM модалки — нет `red`/`#a33`/`--wolf-danger`, нет
  `role="alert"`.

## Out of Scope

- Фильтры на общей диаграмме (какие проекты/рутины отображать) — отдельный тикет 07.
- Миграция/хранение порядка проектов в БД — вне объёма (см. тикет 05).
- Автоматический пересчёт `totalPlanHours` из кривой — объём задаётся пользователем
  отдельно (поле «План, часы»); кривая распределяет его во времени, но не переписывает
  сам объём автоматически (это решение пользователя при редактировании карточки).

## Answer

Реализовано в ветке `release-0.8/feature/06-project-curve-editor`.

- Новый переиспользуемый компонент `web/src/components/LoadCurveLane.vue` — дорожка
  кривой одного проекта. Геометрия и взаимодействие идентичны вкладке «Кривые»
  (тикет 03): перетаскивание ручки (часы + месяц перехода), клик по дорожке добавляет
  точку, двойной клик по точке удаляет (кроме первой), мобильная текстовая форма,
  клавиатура (←/→ месяц, ↑/↓ часы, Delete удаляет). Работает автономно: сама грузит
  `GET /projects/{id}/load-curve` и пишет через `useLoadChartWrite`
  (`PUT/DELETE /projects/{id}/load-curve`, дебаунс 400 мс, откат при ошибке). Если
  `startMonday`/`horizonMonths` не переданы пропсами (страница проекта), подтягивает их
  одним `GET /planning/load-charts`.
- `CurvesTab.vue` отрефакторен: тело дорожки заменено на `<LoadCurveLane>` для каждого
  проекта (контракт вкладки не изменился — шкала месяцев, суммарная строка, запись те же).
- `ProjectDetailView.vue`: на карточке проекта — кнопка «Распределить время» рядом с
  «Изменить»; по клику открывается доступная модалка (`role="dialog"`, закрытие по Esc и
  клику вне) с одним `<LoadCurveLane>` для этого проекта + объём («план N ч») + подпись
  плана. Подпроекты покрываются, т.к. открываются как отдельные `/projects/{id}`.
- Тихий контракт 0.3: только токены `--wolf-*`, без `red`/`--wolf-danger`/`role="alert"`.

Проверка: `npm run build` зелёный (114 модулей); геометрия/взаимодействие переиспользованы
из рабочей вкладки «Кривые» (тикет 03). Визуальный гейт (браузерная DOM-инспекция) — ручная
приёмка при поднятом стеке.
