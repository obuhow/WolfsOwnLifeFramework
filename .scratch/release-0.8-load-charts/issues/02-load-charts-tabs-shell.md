# Каркас «Диаграммы нагрузки»: замена секции «План нагрузки» на переключатель вкладок

Status: ready-for-agent
Blocked by: 01
Blocks: 03, 04, 05

## Question

Заменить две плоские таблицы секции `#load-plan` на оболочку с четырьмя вкладками и общей загрузкой данных. Тикет отвечает за каркас и общий контракт оформления; сами диаграммы приходят тикетами 03–05.

## Что сделать

1. **Новый компонент `web/src/components/LoadCharts.vue`.** Заменяет содержимое секции `#load-plan` внутри `PlanningView.vue`. Обе существующие таблицы (`capacity-list` и `curve-list`) удаляются — их данные полностью покрыты новым эндпоинтом.
2. **Якорь и маршрут не меняются.** `/roadmap#load-plan` продолжает работать и ведёт на ту же секцию. Новый маршрут не создаётся, пункт меню не добавляется, структура навигации релиза 0.5 не трогается.
3. **Заголовок секции остаётся «План нагрузки»** (термин закреплён в `CONTEXT.md`), eyebrow — «Нагрузка». «Диаграммы нагрузки» — подпись переключателя вкладок, не замена названия секции.
4. **Четыре вкладки:** Кривые · Бюджет · Лестница · Очередь. Реализуется `role="tablist"` со стрелочной навигацией и `aria-selected`. Панели вкладок 03–05 подключаются своими тикетами; в этом тикете каждая — заглушка с текстом «подключается в тикете NN».
5. **Состояние вкладки.** Активная вкладка пишется в `localStorage` (`wolf.loadCharts.tab`) и отражается в URL как query (`/roadmap?chart=curves|budget|ladder|queue`), чтобы вид передавался ссылкой. Приоритет при открытии: query → localStorage → «Кривые».
6. **Единая загрузка данных.** Один вызов `GET /api/v1/planning/load-charts` на всю секцию, результат передаётся вкладкам пропсами. Переключение вкладки не перезапрашивает данные. Состояния: загрузка, ошибка (строкой, `--wolf-ink` + нижнее правило, как текущий `.banner.error`), пусто («Нет активных проектов»).
7. **Общий контракт оформления** для всех вкладок — токены `web/src/style.css`: `--wolf-surface`, `--wolf-ink`, `--wolf-muted`, `--wolf-faint`, `--wolf-rule`, `--wolf-subrule`. Без теней, скруглений, градиентов, прогресс-баров и иконок предупреждения. Все часы и даты — `font-variant-numeric: tabular-nums`. Перебор нормы — текстом и штриховкой, **без сигнального цвета**.
8. **Общий хелпер записи** для тикетов 03–05: функция отправки изменения с дебаунсом 400 мс после завершения жеста и откатом к серверному значению при ошибке `PUT` (значение возвращается, под диаграммой появляется строка ошибки). Живёт в `LoadCharts.vue` или соседнем модуле, не дублируется в каждой вкладке.

## Testing Decisions

- Ручная приёмка: `/roadmap` — секция «План нагрузки» показывает четыре вкладки; старые таблицы отсутствуют.
- Переключение вкладок не вызывает повторный запрос `load-charts` (вкладка Network).
- Открытие `/roadmap?chart=ladder` открывает «Лестницу»; после переключения на «Очередь» и перезагрузки страницы без query открывается «Очередь».
- `/roadmap#load-plan` прокручивает к секции.
- Клавиатура: `Tab` доходит до переключателя, ←/→ меняют вкладку, `aria-selected` соответствует видимой панели.
- Тихий контракт 0.3: инспекция DOM — нет `red`/`#a33`, нет `role="alert"`, нет прогресс-баров.
- Гейт визуального тикета: сборка `web` → пересоздание контейнера → сверка отдаваемого хэша ассетов с `web/dist/assets` → аутентификация в браузере → hard refresh → инспекция DOM.

## Out of Scope

Содержимое четырёх вкладок (тикеты 03, 04, 05). Изменения в `GanttView.vue` — верхняя часть страницы Дорожная карта не трогается.
