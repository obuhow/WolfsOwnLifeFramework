Status: ready-for-agent
Blocked by: 02
Type: task

## Вопрос

Заявка (Дорожная карта): «Порядок вкладок: Бюджет, План нагрузки». По уточнению владельца
(grill-with-docs реш. C) имелся в виду порядок вкладок **на странице «План нагрузки»**:
**Бюджет, Кривые, Лестница, Очередь** («План нагрузки» — имя самой страницы из тикета 02,
а не вкладки).

## Доказательство текущего состояния

`web/src/components/LoadCharts.vue:39-45` — текущий порядок:

```js
const TABS = [
  { key: 'curves', label: 'Кривые', ticket: '03' },
  { key: 'budget', label: 'Бюджет', ticket: '04' },
  { key: 'ladder', label: 'Лестница', ticket: '04' },
  { key: 'queue', label: 'Очередь', ticket: '05' },
]
const DEFAULT_TAB = 'curves'
```

Нужен порядок: `budget, curves, ladder, queue`.

## Что сделать

Фронт, `LoadCharts.vue`:

1. Переставить массив `TABS` в порядок **budget → curves → ladder → queue**.
2. `DEFAULT_TAB` — решить с владельцем: оставить `'curves'` или сделать первую вкладку
   `'budget'` дефолтной. По умолчанию тикета — **`'budget'`** (первая слева), но приоритет
   `?chart=` и `localStorage` (`LS_KEY`) сохраняется (`resolveInitialTab`, строки 48-55).
3. Проверить, что deep-link `?chart=<key>` и ARIA-tablist навигация стрелками
   (`onTabKeydown`, `setTab`) работают при новом порядке (индексы `tabRefs` пересчитываются
   от массива — правок логики не требуется, только порядок данных).
4. Не менять сами панели/прогнозы (`BudgetTab`/`LadderTab`/`QueueTab`/кривые,
   `loadChartsForecast.js`).

## Testing Decisions

- Браузер: на `/load-plan` вкладки идут слева направо Бюджет, Кривые, Лестница, Очередь;
  первая активна по умолчанию (если не задан `?chart=`/localStorage).
- `/load-plan?chart=queue` по-прежнему открывает «Очередь»; стрелки ←/→ листают вкладки
  в новом визуальном порядке; `aria-selected` корректен.
- `npm run build` зелёный.
