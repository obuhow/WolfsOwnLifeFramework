## Problem Statement

Пять доработок и один баг, сформулированные Павлом по итогам использования после релиза 1.0.
Затрагивают три экрана — Утренний обход, Дорожную карту / План нагрузки, Ежедневник — и
раздел Документации. Часть требований **противоречит** зафиксированным доменным решениям
(глоссарий `CONTEXT.md`, визуальный контракт релиза 0.3); все противоречия разобраны
grill-with-docs и разрешены явными решениями владельца (см. `grill.md`).

## Решения владельца (из grill-with-docs)

- **A.** Полоса заполнения проекта в Ежедневнике — зелёный факт + светло-зелёный план;
  точечное исключение из контракта 0.3, оформляется **новым ADR**.
- **B.** «План нагрузки» выносится в **отдельную страницу** (`/load-plan`); старый якорь
  `/roadmap#load-plan` → 302. Глоссарий обновлён (секция → страница).
- **C.** Вкладки страницы «План нагрузки»: **Бюджет, Кривые, Лестница, Очередь**.
- **D.** «Распределить время» — ручной редактор кривой, **дополняет** стратегии; инвариант:
  суммарные плановые часы проекта неизменны.
- **E.** *(отменено 2026-08-31)* Прежде: запись «со скольки до скольки» → N слотов по 15 мин.
  **Новая постановка:** режим-тумблер «Карандаш+» для быстрого ±15 мин к слоту сверху/снизу
  записи; плюс фикс бага «вычитание с начала вместо конца» (root cause на фронте —
  запись рендерится одной кнопкой, слот всегда берётся с верха блока). См. тикет 07.
- **G.** h1 «Календарь» → «Ежедневник».
- **I.** Правки вёрстки (патч `wolftokensstep1.patch`) — направление «Кабинет»: заливка
  первичной кнопки, радиус контролов, рамки у полей, тёплый danger-акцент, обновлённая
  шкала отступов/типографика, плюс CSS для 94 ранее неописанных классов. Системный
  пересмотр контракта 0.3, оформляется **новым ADR** (не точечное исключение).

## Out of Scope

- Изменение модели «Запись времени» (диапазон реализуется N слотами по 15 мин).
- Замена стратегий Бюджет/Лестница/Очередь единым редактором (кривая их **дополняет**).
- Автоматическая простановка записи по клику на слот (временно **отключается**, не удаляется).

## Further Notes

Новый ADR (`docs/adr/0006-*`) фиксирует исключение из quiet-register контракта 0.3 для
полосы заполнения проекта (зелёный факт + светло-зелёный план). Без него тикет 06
противоречит релизу 0.3.

Второй новый ADR (`docs/adr/0007-*`) фиксирует системный пересмотр контракта 0.3 в части
заливки/радиуса/рамок/danger-цвета управляющих элементов и шкалы отступов/типографики —
направление «Кабинет» из патча вёрстки, принесённого владельцем в конец релиза. В отличие
от ADR-0006 (точечное исключение одного элемента), это ревизия контракта целиком; без
него тикет 09 противоречит релизу 0.3. Остальные пункты контракта 0.3 (белая поверхность,
без теней/синего/прогресс-баров, зелёный только за фактом) ADR-0007 не отменяет.
