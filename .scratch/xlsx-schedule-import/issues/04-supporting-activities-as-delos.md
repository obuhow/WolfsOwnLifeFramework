# 04: Поддерживающие активности как Дела с пометкой

**What to build:** Поддерживающие активности (Сон, Еда, В дороге, Питание, Обед…) при импорте
становятся Делами, но помечены как «поддерживающие» — чтобы их можно было отличать и
группировать при взгляде (разговорно «Рутина»), не путая с Делами-единицами работы. «Сон» не
дублируется — переиспользует существующее Дело механизма «Ночные часы».

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Новый флаг «поддерживающее» у сущности `Delo` (миграция **V43**; следующая после V42)
- [ ] При маппинге активности пользователь может пометить создаваемое Дело как «поддерживающее»
- [ ] «Сон» (и вариации регистра) → привязывается к существующему Делу «Сон» (Ночные часы), без создания дубля
- [ ] Флаг доступен в ответах API Дела (для будущей группировки в отображении и в контексте агента)
- [ ] Поддерживающие Дела остаются обычными Делами для модели (Записи времени ссылаются на них как на Дела; отдельной сущности Рутина не вводим)
- [ ] Тест: импорт активности из списка поддерживающих → Дело с флагом; «Сон» → без дубля
- [ ] Решить в реализации (О-2): новый boolean-столбец vs переиспользование существующего тега/поля — обосновать в Answer
