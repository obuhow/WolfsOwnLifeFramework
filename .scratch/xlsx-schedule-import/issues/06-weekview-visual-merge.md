# 06: Визуальная склейка подряд идущих Записей в WeekView

**What to build:** В недельном календаре подряд идущие одинаковые 15-минутные Записи
показываются одним блоком (напр. «Java 09:00–11:00»), а не восемью отдельными плитками —
чтобы импортированное полугодие читалось глазами. Косметика поверх хранения: в БД по-прежнему
N отдельных 15-мин Записей (модель WOLF не меняется).

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] В `WeekView` соседние по времени Записи с одним и тем же Делом (и статусом) отображаются одним визуальным блоком
- [ ] Хранение не меняется — склейка только на уровне отображения; клик/редактирование по-прежнему оперируют 15-мин ячейками
- [ ] Разрыв (пустой слот) или смена активности завершает блок
- [ ] Проверить (О-1): есть ли уже частичный механизм в `WeekView`; если да — расширить, не дублировать
- [ ] `npm run build` зелёный; поведение существующего календаря не сломано
