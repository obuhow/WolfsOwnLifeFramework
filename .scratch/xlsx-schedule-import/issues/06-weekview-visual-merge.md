# 06: Отображение и редактирование интервальных Записей в WeekView

**What to build:** В недельном календаре интервальная Запись показывается одним блоком
(например, «Java 09:00–11:00»). Непрерывный блок не должен дробиться на восемь плиток ни
при импорте, ни при обычном отображении: в БД хранится одна строка с `startAt/endAt`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] В `WeekView` интервальная Запись отображается одним блоком с началом и концом
- [ ] Хранение и API используют одну строку на непрерывный блок; клик/редактирование меняют границы с шагом 15 минут
- [ ] Разрыв (пустой слот) или смена активности завершает блок
- [ ] Изменение границы склеивает соседние интервалы с тем же содержимым и статусом; разрез оставляет две строки
- [ ] Проверить (О-1): WeekView не создаёт и не ожидает N строк на один непрерывный блок
- [ ] `npm run build` зелёный; поведение существующего календаря не сломано
