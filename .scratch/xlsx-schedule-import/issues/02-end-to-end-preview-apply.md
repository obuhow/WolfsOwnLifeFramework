# 02: Сквозной импорт happy-path (preview → apply)

**What to build:** Полный путь пользователя: на странице `/import/xlsx` загружаю
`Расписание.xlsx` → вижу **сводку предпросмотра** (сколько недель, заполненных ячеек,
активностей — новых vs уже сопоставленных с Делами) → жму «Применить» → в календаре
появляются мои реальные Записи времени. Первый момент «я вижу своё полугодие в WOLF».

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `POST /import/xlsx` разбирает файл парсером (тикет 01) и возвращает **preview без записи в БД**: недели, число ячеек, список активностей с флагом «новая/известная», предварительное число создаваемых Записей
- [ ] Отдельное действие «Применить» материализует **N отдельных 15-мин Записей времени `DONE`** (одна ячейка = одна Запись; модель WOLF не меняется)
- [ ] Известные активности (есть в `activity_mapping`) → Записи привязаны к Делу; неизвестные → механизм вопросов (`xlsx_import_question`), как сейчас
- [ ] Время трактуется как локальное время пользователя (07:00 в файле → `startAt` дата T07:00), без UTC-конверсий
- [ ] Дедуп по хешу файла сохраняется (повторная загрузка того же файла не плодит прогоны)
- [ ] UI `/import/xlsx` (`XlsxImportView`): загрузка → экран сводки → кнопка «Применить» → результат (создано Записей, число вопросов по неизвестным)
- [ ] `*ApiIT` на happy-path: загрузка образца → preview → apply → ожидаемое число Записей `DONE` за период; `npm run build` зелёный
- [ ] Обратная совместимость `ImportResponse`: старые поля сохранены, preview-поля добавлены
