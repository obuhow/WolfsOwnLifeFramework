## Контекст (из спайка)

Реальный файл `Расписание.xlsx` — недельная сетка (11 листов, 1 июня – 16 авг 2026),
1943 ячейки-активности, 67 уникальных активностей. Структура регулярная. В WOLF уже есть
`XlsxImportService` (миграция V24: `activity_mapping` — маппинг активность→Дело с обучением;
`xlsx_import_question` — вопросы по неизвестным; дедуп по хешу файла; статусы
PLANNED/DONE/UNKNOWN), но он НЕ читает конкретно этот формат (4 дефекта — см. ANALYSIS.md:
дата из имени листа, смещение слотов, колонки дней A–G vs D–J, блок «Факт»).

Направление: **чинить/расширять `XlsxImportService` под формат**, НЕ строить LLM-конвертер.

## Формат файла (подтверждён спайком — для парсера)

- Лист = неделя; имя листа «N-M месяц» (даты в имени НЕТ → брать из строки данных).
- **row 1** = даты-серийники Excel (колонки D–J); **row 2** = заголовки дней.
- **Дни Вс–Сб**: колонка D = воскресенье (СДВИГ на 1 относительно Пн-Вс!).
- Время — колонка C (дробь Excel), день начинается ~07:00.
- Активности — колонки D–J, строки-слоты (где C — время-дробь).
- Внизу листа блок «Факт» (часы по категориям) — **игнорировать**.
- Серийник→дата: Excel-1900 с компенсацией бага високосного 1900.

## Технические требования (выведены)

- **Т-1** «Сон» → существующее Дело (Ночные часы), без дубля.
- **Т-2** Парсер: даты из row 1 серийников, дни Вс–Сб (сдвиг), время из колонки C, активности
  D–J, отсечь блок «Факт». Заменяет дефектную логику `parseWeek`/смещения в `XlsxImportService`.
- **Т-3** Preview-слой (И-I): разобрать без записи → сводка → apply. Новый слой поверх
  текущего «пишет сразу».
- **Т-4** Конфликты (И-G/H): подсчёт занятых ячеек → развилка пропустить/перезаписать/отменить.
  Сейчас только молчаливый `continue` — расширить.
- **Т-5** Пометка «поддерживающее» у Дел (И-B): тег/флаг + группировка в отображении.

## MVP-разрез (предложение для spec)

**В MVP:**
1. Парсер формата (Т-2) — читает реальный файл, N×15-мин DONE (И-D).
2. Preview → apply (И-I) со сводкой.
3. Маппинг активность→Дело «по неизвестным» (уже есть) + поддержка класса 1 как Дел (И-B),
   двухступенчатая нормализация (И-E), «Сон» без дубля (Т-1).
4. Конфликты сводкой (И-G/H).
5. Точка входа — `/import/xlsx` (И-J).

**НЕ в MVP (осознанно потом):**
- Материализация UNKNOWN на пустые ячейки (И-C1, вариант «б») — только если понадобится.
- Поячеечное/погруппное разрешение конфликтов (в2/в3).
- LLM-конвертер действительно свободных таблиц (не про этот файл).
- Отдельная сущность Рутина с квотой из импорта (И-B: пока Дела с пометкой).
