## Находки, которые spike выявил (важны для spec импорта)

1. **Дни недели сдвинуты на 1**: колонка D = **воскресенье** (не понедельник). Лист
   «1-7 июня»: D1=2026-05-31 (Вс) … J1=2026-06-06 (Сб). Импорт обязан это учитывать.
2. **Строка 1 (r=1) = даты-серийники; строка 2 (r=2) = заголовки дней.** (Ранее по
   read_file казалось наоборот — spike поправил: row r=1 даты, r=2 «Понедельник…».)
3. **Даты недель начинаются с воскресенья** — лист «8-14 июня» начинается 2026-06-07 (Вс).
4. **67 уникальных активностей**, включая спец-маркеры:
   - «Неизвестно» (46) — вероятно, надо НЕ грузить как Дело;
   - «Отдых» (237), «Уезжаю на отдых» (228), «в дороге» (85), «сон»/«Сон» — контекст,
     почему нет записей по проектам (отпуск), не Дела;
   - вариации одного: «Спортзал»/«в спортзал», «Сон»/«сон», «Английский клуб»/«Клуб
     английского», «Настройка окружения»/«Настройка окружения. Подключение второго монитора».
5. **Время начала дня = 07:00** (первый слот в файле ~07:00, серийник 0.2916…) — не полночь.
