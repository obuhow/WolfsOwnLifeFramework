# Тикет 03 — Фиксация факта на стадии «Поток»

Status: needs-triage
Blocked by: 01, 02
Type: task

## Вопрос

Завершать воронку реальной Записью времени, не вводя скрытый таймер.

## Что сделать

- на стадии `FLOW` использовать существующее создание/завершение Записи времени;
- соблюдать модель непрерывного интервала `[start_at, end_at)` и шаг сетки 15 минут;
- явно показать результат записи пользователю;
- при занятой ячейке вернуть существующее понятное состояние конфликта.

## Testing Decisions

- Запись создаётся только после действия пользователя на стадии `FLOW`.
- Повторная отправка не создаёт дубликат.
- Время и часовой пояс совпадают с обычным вводом Ежедневника.
- Ошибка записи видима; стадия не отмечается завершённой при неуспехе.
