# Тикет 02 — Воронка на Ежедневнике в обоих режимах

Status: needs-triage
Blocked by: 01
Type: task

## Вопрос

Вынести точку входа из условного `FocusPanel` на общий контекст ячейки/Главного
дела Ежедневника.

## Что сделать

- показать воронку при `PARALLEL_SLOTS` и `PRIMARY_FOCUS`;
- сохранить действующий FocusPanel для специальных фокусных функций;
- связать вход из заметки агента с выбранным Делом без автоматической записи;
- использовать существующие API и правила текущего пользователя.

## Testing Decisions

- Оба режима дают одинаковый набор стадий.
- В режиме параллельных слотов воронка не исчезает вместе с FocusPanel.
- Нельзя открыть чужое Дело через ссылку на воронку.
- Переходы не меняют чужие или архивные записи.
