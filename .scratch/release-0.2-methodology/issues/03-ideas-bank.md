# 03 — Банк Идей: CRUD + категории + Синергия + промоушн в Проект

**What to build:** Личный Банк Идей для "ещё не проектов". Идея: название, описание, категория (бизнес / музыкальные / личные / криповые), статус (в банке / в работе / архив), Синергия со Сферами жизни (из тикета 01). `POST /ideas/{id}/promote` создаёт Проект, копирует название/описание/Синергию, переводит Идею в статус "в работе". Категория "криповые" не фильтруется и не модерируется (личное пространство).

**Blocked by:** 01 — Справочник Сфер жизни + CRUD Синергии (нужна Синергия).
