# 14 — Календарь: переименование страницы «Неделя» + месячный вид (Outlook-раскладка)

**What to build:** Страница «Неделя» (0.1) переименовывается в **Календарь** (`/week` → `/calendar`, старый путь редиректит). На Календаре — переключатель вида **Неделя | Месяц**. Недельный вид — существующая 15-мин сетка без изменений. Месячный вид — раскладка как в Outlook: по горизонтали дни недели Пн..Вс, по вертикали — недели месяца, в ячейке дня — список Дел этого дня (компактно, по времени начала). Вид и дата живут в URL (`/calendar?view=month&date=2026-08`), чтобы ссылка воспроизводила экран.

**Blocked by:** None — can start immediately.

**Status:** resolved

- [ ] Роут `/calendar`, редирект с `/week`, пункт меню «Календарь» (RU-копирайтинг во всех местах, включая заголовки и хлебные крошки)
- [ ] Переключатель `Неделя | Месяц`, состояние в query-параметрах (`view`, `date`), сохранение последнего выбранного вида в localStorage
- [ ] `GET /api/v1/calendar/month?month=YYYY-MM` — агрегация по дням: `[{date, entries: [{id, startAt, deloId, deloTitle, projectId, projectTitle, status}], totalCount}]`
- [ ] Сетка месяца: 6 строк × 7 колонок, недели по ISO (первый день недели — понедельник), дни соседних месяцев приглушены
- [ ] Ячейка дня: до 3 записей + «ещё N», клик по «ещё N» / по дате → недельный вид на этой неделе с фокусом на дне
- [ ] Цветовая метка Проекта у записи (наследуем палитру 0.1), статус «неопределено»/«unknown» — без красного
- [ ] Клик по пустой части ячейки дня → переход в недельный вид на этот день (создание Записи в месячном виде не делаем — время не выдумываем)
- [ ] Навигация месяц назад/вперёд + кнопка «Сегодня», текущий день выделен нейтрально (рамка, не заливка)
- [ ] Производительность: один запрос на месяц, без N+1 по дням
