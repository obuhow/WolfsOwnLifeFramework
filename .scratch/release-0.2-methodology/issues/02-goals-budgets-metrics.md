# 02 — Цели: CRUD + недельные бюджеты + метрики + приоритеты + фактические часы

**What to build:** Пользователь управляет Целями (верхнеуровневые векторы на 6 месяцев): доход 40к+/мес, вес 103→87 кг, ISTQB+5 проектов, трек с DJ. У Цели — приоритет (1..N, уникальный), недельный бюджет часов, набор метрик (вес кг, доход ₽, количество проектов, % готовности трека) с историей значений. Цель связана с Проектами (many-to-many). `GET /goals/{id}/fact?week=YYYY-Www` агрегирует фактические часы за ISO-неделю из Записей времени 0.1 по всем Проектам Цели с учётом Режима учёта часов пользователя (primary_only / all_projects). Бюджет корректируется без штрафов — план меняется под реальность.

**Blocked by:** None — can start immediately (независимо от 01).

**Status:** resolved
