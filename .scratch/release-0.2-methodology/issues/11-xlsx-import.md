# 11 — XLSX Import: парсер недельной сетки + словарь маппинга + статус "Неизвестно" + интерактив

**What to build:** Импорт xlsx-файла учёта времени (апрель 2026 → сейчас): каждый лист — неделя, колонки — дни Пн..Вс, строки — 15-мин ячейки 00:00..23:45, в ячейке текст активности. `POST /api/v1/import/xlsx` (multipart) → парсинг → для каждой непустой ячейки поиск в словаре `activity_mapping` (текст → Дело). Найдено → Запись времени со статусом "выполнена", привязка к Делу. Не найдено → импорт ставится на паузу, пользователь отвечает через `POST /import/xlsx/{id}/resolve {activityText, deloId | createDelo: {title, projectId}}` → словарь пополняется → импорт продолжается. Пустые ячейки → Запись времени со статусом **"Неизвестно"** (новый статус, не путать с "неопределено"). Импорт идемпотентен (повторная загрузка того же файла не дублирует Записи). UI: загрузка файла, прогресс, экран разрешения неизвестных активностей.

**Blocked by:** None — can start immediately.
