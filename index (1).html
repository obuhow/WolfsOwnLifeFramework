04 — Проекты

Приложения с Live-demo на GitHub

TT
TicTacToeWebGame · Крестики-нолики
Java 21 · Spring Boot 3 · PostgreSQL · Docker

Полноценный backend-проект для портфолио Java-разработчика: REST API, БД, авторизация, CI/CD, документация. Пишу весь код самостоятельно, использование LLM только для ревью и помощи в документировании.

Архитектура (легко поддерживать)
  • Разделение на слои: datasource / domain / web / security / di / util
  • Доменные модели отделены от JPA-сущностей через мапперы
  • Кастомный фильтр Basic Auth, конфигурация Spring Security
Документация
  • Swagger UI — интерактивная документация API
  • Postman-коллекции для ручного и авто-тестирования
  • Release-notes и release-plan для каждой версии
  • README с инструкциями по запуску и тестированию
Планирование релизов
  • Релизы: релиз 1.0 завершён, релиз 1.1 в плане
  • User Stories и технические задачи для каждого релиза
  • CI/CD через GitHub Actions: автосборка → автодеплой на Cloud.ru
