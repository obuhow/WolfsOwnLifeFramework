# WOLF

Самостоятельная оцифровка жизни: одно тёплое место для работы, здоровья, семьи, денег и отдыха. Слоган: «Уютно. Тихо. Под вашим контролем».

## Language

**Дело**:
Переиспользуемый тип активности пользователя (шаблон): что это за занятие само по себе, без привязки к конкретному моменту времени.
_Avoid_: Задача (как единственный синоним), Task, To-do без уточнения; не путать с Записью времени

**Запись времени**:
Конкретный факт или план в одной 15-минутной ячейке календаря; ссылается на Дело либо несёт ad-hoc текст без Дела. В одной ячейке (Пользователь × начало интервала 15 мин) — не больше одной Записи. Статусы: неопределено (пусто/нет решения), запланирована (план, в т.ч. ещё не подтверждённое прошлое), выполнена (подтверждённый факт).
_Avoid_: Слот (разговорно ок, в модели — Запись времени), Дело (для ячейки), Event, Appointment

**Область жизни**:
Устойчивая категория жизни пользователя (работа, здоровье, семья, деньги, отдых и т.п.); рамка задаётся пользователем. Не имеет сроков проекта.
_Avoid_: Домен (синоним в UI ок, в модели — Область жизни), Категория, Тег, Проект

**Проект**:
Цель или инициатива пользователя, принадлежит одной Области жизни; опционально имеет сроки и плановые часы. Может содержать вложенные проекты (подпроекты — тот же тип).
_Avoid_: Область жизни, Эпик (как замена), Initiative

**Связь Дело–Проект**:
Дело может быть прикреплено к нулю, одному или нескольким Проектам. Дело без проекта — валидная рутина/личное.
_Avoid_: «Дело всегда в проекте»

**Бэклог недели**:
Набор Дел, которые пользователь намерен сделать на выбранной неделе, ещё не разложенных (или не полностью разложенных) по Записям времени. Отдельная «корзина» намерения на неделю, не Проект и не статус Записи времени.
_Avoid_: Backlog продукта, Inbox, просто «все дела без даты»

**Способ исполнения**:
Атрибут Дела: кто/как это делается — сам пользователь, можно делегировать, можно автоматизировать. Задаёт фильтры списков на «Сегодня».
_Avoid_: Assignee как обязательная сущность в 0.1, отдельный статус Дела

**Пользователь**:
Владелец своего личного пространства: Областей жизни, Проектов, Дел, Записей времени и настроек. В 0.1 нет совместного доступа между пользователями.
_Avoid_: Аккаунт команды, Workspace (как shared), Роль admin в домене (admin — только seed-логин)

**Seed-аккаунт `admin`**:
Исторический преднастроенный пользователь (`admin/admin`), созданный `DataInitializer` для однопользовательского режима до релиза 0.4. С тикета 13 доступ к нему закрыт: `status='BLOCKED'` и пароль сброшен на случайный. Данные `admin` не удалены. Рабочий администратор системы — именной аккаунт `obuhov`.
_Avoid_: `admin/admin` как рабочий вход, удаление пользователя `admin`, разблокировка при рестарте контейнера

**Демо-профиль**:
Декларативное описание предзаполненного набора данных пользователя (`assets/profiles/<slug>.json`): области жизни, проекты (со сроками относительно «сегодня»), Дела, цели, рутины, заметки. Загружается в аккаунт при первом входе (онбординг) или повторно из Настроек.
_Avoid_: реальные данные пользователя, аккаунт команды

**Демо-пользователь**:
Временный аккаунт, созданный из демо-профиля гостем через демо-режим; логин вида `GoodEnoughDemoUser-<Буква><N>`, пароль совпадает с логином; помечен `accountType='DEMO'` и удаляется администратором вручную. Отличается от seed-аккаунта `admin`.
_Avoid_: рабочий аккаунт, авто-удаляемый по расписанию, admin как рабочий вход

**Демо-режим**:
Точка входа на неавторизованном экране: кнопка «Демо-режим» открывает выбор демо-профиля и создаёт демо-пользователя.
_Avoid_: онбординг (тот требует уже аутентифицированного пользователя)

**Ночные часы**:
Настраиваемый Пользователем суточный интервал, в котором по умолчанию скрыты строки сетки и автоматически подставляется Дело «Сон», если Пользователь не поставил другую Запись времени.
_Avoid_: «Тихие часы» уведомлений, Do Not Disturb ОС

**План на неделю**:
Плановое число часов на Проект в конкретной ISO-неделе; задаётся на Гантте, не выводится из Записей времени.
_Avoid_: Запись времени, Forecast

**Основной проект Дела**:
Среди Проектов, к которым прикреплено Дело, один отмечен как основной. Используется при режиме учёта часов «только primary».
_Avoid_: Единственный проект (Дело по-прежнему может иметь несколько)

**Режим учёта часов**:
Настройка Пользователя для Гантта: считать часы Записи времени только в Основной проект Дела (default) либо полностью в каждый прикреплённый Проект.
_Avoid_: Жёстко один способ навсегда в коде без настройки

**Правило повторения**:
Простое расписание Дела: выбранные дни недели и (опционально) время/окно; при применении создаёт будущие Записи времени на ограниченный горизонт. Не полный RRULE.
_Avoid_: Cron, RRULE, «бесконечное» правило без горизонта

**Режим фиксации времени**:
Настройка Пользователя: каким способом вводится факт. «Параллельные слоты» — управление 15-минутными Записями времени (поведение 0.1). «Фокус» — одно Главное дело на интервал плюс чек-лист Отметок переключения. Не влияет на разнос часов по Проектам.
_Avoid_: Режим учёта часов (это другая настройка), Режим работы, Pomodoro-режим, Focus mode как таймер принуждения

**Главное дело**:
Дело, выбранное Пользователем на текущий интервал в режиме «Фокус». Именно оно материализуется в Записи времени при закрытии Фокус-сессии.
_Avoid_: Основной проект Дела (0.1 — про Проект, не про Дело), Приоритетная задача, Current task

**Фокус-сессия**:
Интервал с одним Главным делом (начало, конец, набор Отметок переключения). Открытая сессия у Пользователя одна. При закрытии превращается в Записи времени статуса «выполнена» на покрытые 15-минутные ячейки.
_Avoid_: Помидор, Таймер, Sprint, Сессия как HTTP-сессия

**Отметка переключения**:
Событие внутри Фокус-сессии: уход на другое Дело (или свободный текст), время, опционально минуты. Фиксация факта в один тап. Не создаёт Запись времени, не занимает ячейку, не вычитает часы у Главного дела автоматически.
_Avoid_: Отвлечение как нарушение, Прерывание, Штраф, Interruption с негативной окраской, Запись времени

**Разбор переключений**:
Добровольный шаг после Фокус-сессии (или в конце дня): Отметки переключений превращаются в часы на соответствующие Дела кратно 15 минутам. Можно не делать — тогда часы остаются на Главном деле. Обратим.
_Avoid_: Уточнение учёта, Сверка, Обязательный шаг закрытия дня, Тайм-шит

**Бэклог месяца**:
Набор Дел, которые Пользователь намерен сделать в выбранном календарном месяце, ещё не разложенных по неделям. Живёт рядом с Бэклогом недели на странице Календарь в месячном виде; перенос в неделю — явное действие.
_Avoid_: Бэклог недели, Roadmap, «всё, что не сделано»

**Чек-лист дня**:
Лёгкий список первоочередного на конкретную дату с галочками выполнения. Пункт не является Делом и не является Записью времени, часов не несёт, по Проектам не разносится. Невыполненные пункты не переносятся автоматически.
_Avoid_: Дело, Запись времени, To-do как основная сущность, Дневной план часов

**Календарь** (страница):
Экран сетки времени с двумя видами: недельным (15-минутная сетка, поведение 0.1) и месячным (дни недели по горизонтали, недели по вертикали, список Дел в ячейке дня). До 0.2 назывался «Неделя». С 1.1 как видимый заголовок страницы заменён на «Ежедневник»; «Календарь» остаётся именем внутренней сетки/вкладки «Неделя».
_Avoid_: Неделя (устаревшее название страницы), Расписание, Планировщик; «Календарь» как заголовок страницы (устарело с 1.1 в пользу «Ежедневник»)

**Планирование** (страница):
Экран с диаграммой Гантта, плановыми часами Проектов, равномерным распределением часов по дням/будням и суммарной плановой нагрузкой. До 0.2 назывался «Диаграмма Ганта». С 0.5 — «Дорожная карта».
_Avoid_: Диаграмма Ганта (устаревшее название страницы), Дашборд, Отчёт

**Суммарная плановая нагрузка** / **План нагрузки**:
Сумма плановых часов всех активных Проектов по ISO-неделям в сравнении с доступными часами Пользователя в неделю. Показывает дельту, ничего не запрещает и не блокирует. С 0.5 раздел внутри Дорожной карты называется «План нагрузки» (ранее «Кривые нагрузки»).
_Avoid_: Capacity как жёсткий лимит, Перегруз как ошибка, Загрузка ресурса (терминология из корпоративных PM-систем)

**Дорожная карта** (страница):
Название страницы «Планирование» в меню навигации с релиза 0.5. Раньше «Диаграмма Ганта». Маршрут `/roadmap`. Старые маршруты `/gantt` и `/planning` — редиректы 302.
_Avoid_: Гантт, Диаграмма Ганта как название страницы

**План нагрузки** (страница):
Экран суммарной плановой нагрузки и детализации по проектам с вкладками «Бюджет», «Кривые», «Лестница», «Очередь». До 0.5 назывался «Кривые нагрузки», в 0.5–1.0 был секцией-якорем внутри Дорожной карты (`/roadmap#load-plan`). С 1.1 — **отдельный маршрут** (`/load-plan`); старый якорь `/roadmap#load-plan` — редирект 302.
_Avoid_: Кривая нагрузки, Кривые нагрузки как название раздела; секция/якорь внутри Дорожной карты (устарело с 1.1)

**Утренний обход** (страница):
Ежедневный ритуал и точка входа после логина (маршрут `/morning`). С 0.5 — первый пункт верхнего меню.
_Avoid_: Утренний ритуал как простое синоним, Morning

**Ежедневник** (страница):
Объединённый экран календаря с вкладками «Неделя» (`/calendar`), «Сегодня» (`/today` — deep link), «Месяц» (`/calendar?view=month`). До 0.5 — разделенные пункты «Календарь» и «Сегодня».
_Avoid_: Неделя / Сегодня как отдельные пункты меню

**Диаграмма компетенций** (страница):
Справочник сфер жизни + вкладка «Синергия» (поглощена из отдельного экрана). Маршрут `/competency`. До 0.5 назывался «Сферы жизни» (`/spheres`). Старый `/spheres` и `/synergy` — редиректы 302. «Сферы жизни» как термин уходит из UI, оставляя «Области жизни» для группировки проектов — не путать.
_Avoid_: Сферы жизни (устаревшее название экрана), Синергия как отдельный пункт меню

**Личная база знаний** (страница):
Заметки, источники и материалы агента. Маршрут `/knowledge`. До 0.5 назывался «Заметки / LLM Wiki» (`/notes`). Старый `/notes` — редирект 302.
_Avoid_: Заметки / LLM Wiki, Notes

**Синхронизация данных**:
Явный пользовательский обмен полным или выбранным набором данных WOLF через версионированный workbook: сначала preview, затем атомарное применение. По умолчанию синхронизация делает upsert по стабильным внешним идентификаторам и ничего не удаляет; удаление возможно только отдельной явно выбранной операцией.
_Avoid_: Live calendar sync, автоматический backup, замена данных по названию, молчаливое удаление

**Внешний идентификатор**:
Стабильный ключ сущности в файле обмена, используемый для upsert и разрешения связей. Не является внутренним database id и не передаётся как authoritative идентификатор.
_Avoid_: database id, название как ключ, UUID пользователя

**Preview импорта**:
Полный результат разбора и валидации файла до записи: план create/update/skip/delete, разрешённые связи, checksum и построчные ошибки. Невалидный preview нельзя применить.
_Avoid_: частичный импорт, dry-run без отчёта, автоматическое применение

**Полоса заполнения проекта**:
Полоса под Проектом в бэклоге Ежедневника, показывающая недельную загрузку Проекта: тёмным акцентом (зелёным) — доля выполненного факта, светло-зелёным — доля запланированного, относительно недельного плана Проекта. Точечное исключение из quiet-register контракта 0.3 (зелёный обычно только за фактом, план — нейтральный), принятое решением владельца в 1.1 и зафиксированное отдельным ADR.
_Avoid_: прогресс-бар с процентами, generic-зелёный CTA, красный/тревожный сигнал перегруза

**Распределение времени проекта**:
Ручной способ задать План на неделю Проекта кривой загрузки: по датам начала и завершения строится прямая по числу часов; Пользователь ставит точку-разбивку на одной из недель и двигает отдельные сегменты вверх/вниз, при этом остальные сегменты пересчитываются так, что суммарные плановые часы Проекта остаются прежними. Вызывается кнопкой «Распределить время» рядом с плановыми часами Проекта. Дополняет существующие стратегии (Бюджет/Лестница/Очередь), не заменяет их.
_Avoid_: Кривая нагрузки (это суммарная нагрузка по всем проектам), замена стратегий Бюджет/Лестница/Очередь, изменение суммарных часов проекта при перетаскивании

**Направление «Кабинет»** (визуальная система):
Ревизия визуального контракта релиза 0.3 (`docs/adr/0007-cabinet-visual-direction-revision.md`), принятая решением владельца в 1.1: заполненная первичная кнопка (`--wolf-ink` фон) вместо текст-действия с подчёркиванием, скруглённые контролы (`--wolf-radius: 4px`/`--wolf-radius-lg: 6px`, но не pill), рамка `1px solid` у полей вместо одной нижней линии, тёплый danger-акцент (`--wolf-danger-ink`/`--wolf-danger-surface`) для опасных действий вместо нейтрального текста, расширенная шкала отступов и типографика (`--wolf-space-6/7` 32/48px, тело 13.5px/1.5). Токены единым источником истины в `web/src/tokens.css`. Не отменяет из 0.3: белую поверхность, отсутствие теней/синего/прогресс-баров, зелёный только за выполненным фактом (кроме точечного исключения ADR-0006).
_Avoid_: применение частично (без ADR-0007 в целом), распространение на полосу заполнения проекта (это отдельное правило ADR-0006, не текущий токен)
