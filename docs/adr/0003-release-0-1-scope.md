# Release 0.1 scope: calendar OS first, file import, no agents

WOLF 0.1 delivers the personal 15-minute calendar, week grid, Gantt, project/delo settings, night hours, and one-shot **CSV** import (**ICS cancelled — moved to release-cancelled**). It deliberately excludes AI agents, live calendar OAuth sync, full RRULE, and multi-user sharing.

Rationale: stabilize the core time model (Дело vs Запись времени, statuses, hour accounting) before adding autonomous planning. File import satisfies “перенесите хаос” without integration complexity.
