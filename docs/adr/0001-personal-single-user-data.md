# Personal single-tenant data per User

WOLF 0.1 is a personal life system: every Область жизни, Проект, Дело, Запись времени and setting belongs to exactly one Пользователь. There is no shared workspace, family sharing, or cross-user assignment.

«Делегировать / автоматизировать» is a label on a Дело (intent), not assignment to another account. The `admin` user is a development/seed login only, not a domain role.

We rejected multi-user collaboration in 0.1 to keep the calendar and Gantt model simple and aligned with the product promise (quiet, under your control).
