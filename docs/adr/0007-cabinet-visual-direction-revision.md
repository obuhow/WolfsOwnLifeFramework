# 0007 — Пересмотр визуального контракта 0.3: направление «Кабинет»

- Статус: **Принят** (2026-08-31, релиз 1.1) — реализован тикетом `issues/09`,
  browser-check на живом стенде проведён (см. «Приёмка» в конце файла).
- Контекст: WOLF 1.1, доработка вёрстки по патчу `web/src/tokens.css` +
  `web/src/style.css` (заголовок в патче: «Направление "Кабинет"»). Решение владельца
  зафиксировано в этом ADR по итогам batched-clarify при заведении тикета 09.
- Связано: `.scratch/release-0.3-ui-design/spec.md` (визуальный контракт «тихого реестра»),
  ADR-0006 (точечное исключение «полоса заполнения проекта»),
  `.scratch/release-1.1-planning-daily-ux/issues/09-design-tokens-cabinet-rework.md`.

## Проблема

Релиз 0.3 зафиксировал контракт «тихого реестра» как систему на уровне **всего**
приложения (`spec.md` §«Design tokens», §«Typography, rhythm, and surfaces»):

- первичные действия — текстовые с подчёркиванием, **не заливка**;
- поля — одна нижняя линия, **не рамка со всех сторон**;
- радиус — максимум 2px, **никогда pill/скруглённые карточки**;
- «No saturated or semantic red... destructive actions require a plain confirmation
  dialog and a textual verb, **not a red button**»;
- шкала отступов ровно `4, 8, 12, 16, 24, 28, 40px`;
- шрифт `"Helvetica Neue", Helvetica, Arial, system-ui, sans-serif`; тело `13px / 1.45`.

Патч `web/src/tokens.css` (новый файл) + правки `web/src/style.css`, который владелец
принёс для релиза 1.1, вводит новое системное направление **«Кабинет»** — и расходится
с контрактом 0.3 не точечно (как ADR-0006), а по всей системе управляющих элементов:

- `.btn-primary` получает **заливку** `background: var(--wolf-ink)` вместо текст-действия
  с подчёркиванием (было: `background: transparent; border-bottom-color: var(--wolf-ink)`);
- `--wolf-radius: 4px` / `--wolf-radius-lg: 6px` — используются на кнопках, `.icon-btn`,
  инпутах; контракт 0.3 разрешает «at most 2px, never pills»;
- `.input`/`.filter-select`/`.weeks-select select` получают `border: 1px solid` со всех
  сторон (`--wolf-fill` подложка) вместо «single lower rule»;
- новый токен `--wolf-danger-ink: #9B453A` / `--wolf-danger-surface: #F6EDEB` — тёплый
  красно-коричневый акцент для `.btn-danger-text:hover`/`.is-armed` (используется в
  `ConfirmInline.vue`, все шесть мест удаления). Контракт 0.3 прямо запрещает
  «saturated or semantic red» и «a red button» для destructive-действий;
- шрифт меняется на системный стек `ui-sans-serif, -apple-system, ...` вместо
  `"Helvetica Neue", Helvetica, Arial, system-ui, sans-serif`;
- шкала отступов и типографика также смещаются (см. ниже, реш. 2).

Это системный пересмотр направления, а не одно исключение на одном экране — точечная
модель ADR-0006 здесь неприменима.

## Решение

Принять патч как **пересмотр контракта 0.3 в целом** (не точечное исключение), с двумя
явными решениями владельца, зафиксированными при заведении тикета 09:

1. **Заливка/радиус/рамки/danger-акцент.** Контракт 0.3 в частях «первичное действие —
   текст с подчёркиванием», «радиус ≤ 2px, без pill», «поля — одна нижняя линия» и «без
   красного для destructive» — **отменяется** в пользу направления «Кабинет»:
   заполненная `.btn-primary` (`--wolf-ink` фон), `--wolf-radius: 4px`/`--wolf-radius-lg:
   6px`, рамка `1px solid` у полей (`--wolf-fill` подложка вне фокуса, `--wolf-surface` +
   `--wolf-rule` в фокусе), тёплый `--wolf-danger-ink`/`--wolf-danger-surface` для
   `.btn-danger-text`. Применяется **системно**, во всех кнопках/полях приложения, а не
   на одном экране.
2. **Шкала отступов и типографика.** Значения шкалы `--wolf-space-6`/`--wolf-space-7`
   поднимаются с `28px`/`40px` до `32px`/`48px`; базовый текст — с `13px / 1.45` до
   `13.5px / 1.5`. Обновлённые значения зафиксированы новым источником истины
   (`web/src/tokens.css`), заменяя таблицу токенов из `.scratch/release-0.3-ui-design/spec.md`.
3. Остаётся в силе из 0.3 (патч этого не трогает): белая поверхность как единственный
   фон по умолчанию, отсутствие теней, отсутствие синего акцента, зелёный (`--wolf-done-*`)
   зарезервирован за фактом **кроме** точечного исключения ADR-0006, отсутствие
   прогресс-баров/процентов.

Область действия — весь `web/src`, токены переезжают в отдельный файл `tokens.css`,
который становится источником истины вместо инлайн `:root` в `style.css` (импортируется
первой строкой `@import './tokens.css';`).

## Последствия

- `+` единая система токенов в одном файле убирает дрейф значений между компонентами
  (94 использованных, но неописанных класса — отдельно закрывает тикет 09 «Слой 2»).
- `+` заполненная первичная кнопка и рамки у полей ближе к типовым desktop-паттернам —
  повышает узнаваемость управляющих элементов без наращивания цветовой палитры.
- `−` контракт 0.3 «тихого реестра» перестаёт быть буквальным техническим ограничением в
  части заливки/радиуса/рамок/красного — эти пункты `spec.md` 0.3 считать **устаревшими**,
  замещёнными этим ADR. Пункты про белую поверхность, отсутствие теней/синего/прогресс-баров
  и зелёный-только-за-фактом остаются в силе.
- `−` **Это второе подряд исключение из quiet-register после ADR-0006** — но, в отличие от
  ADR-0006 (точечное, один элемент одного экрана), это уже системный пересмотр самого
  контракта. Дальнейшее размывание (третий заход на цвет/форму управляющих элементов)
  должно оформляться не новым ADR-исключением, а явной **новой версией дизайн-релиза**
  (`.scratch/release-X.Y-ui-design-v2/`), пересобирающей `spec.md` целиком, а не патчем
  токенов поверх старого контракта.
- ADR-0006 (полоса заполнения проекта) остаётся в силе без изменений: зелёный-для-плана
  там по-прежнему исключение, зафиксированное отдельно, и не становится общим правилом
  из-за этого ADR.
- Референсная реализация — тикет 09 релиза 1.1
  (`issues/09-design-tokens-cabinet-rework.md`).

## Отвергнутые альтернативы

- **Оставить только совместимую часть патча** (консолидация токенов интервалов/шрифтов,
  94 неописанных класса, tap-target 44px) **без** заливки/радиуса/danger-красного —
  отклонено владельцем: направление «Кабинет» задумано как цельная система, частичное
  применение оставило бы `.btn-primary` и destructive-действия в противоречии с
  остальной вёрсткой.
- **Применить патч без ADR, молчаливо перезаписав контракт 0.3.** Отклонено — контракт
  0.3 фиксирован отдельным релизом и явно перечисляет то, что патч отменяет; молчаливая
  перезапись сделала бы `.scratch/release-0.3-ui-design/spec.md` лживым для следующего
  агента без единой записи о том, что и почему изменилось.
