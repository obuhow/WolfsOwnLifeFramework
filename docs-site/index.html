WOLF — Документация

Wolf's Own Life System — персональная Life OS: учёт времени, планирование недели, Ганта, цели, LLM Wiki.

Введение

Это стартовая страница документации WOLF. Она отдаётся отдельным контейнером (wolf-docs) и доступна по адресу /docs основного домена. Контент смонтирован в nginx через bind-mount, поэтому правка файлов не требует пересборки — достаточно сохранить файл и обновить вкладку.

Стек и порты

СервисТехнологияПорт (host)

Запуск

docker compose up -d
# приложение:      http://localhost/  (wolfs.smallmba.space)
# документация:    http://localhost/docs  (wolfs.smallmba.space/docs)
# документация(local direct): http://localhost:8090

Доменная модель

Ключевые сущности UI: Дела, Сферы жизни, Области жизни, Проекты, Синергия.

Импорт данных

Схема подготовленного CSV для импорта Дел:

title,date,startAt,endAt,description,executionMode,projects,lifeArea
  • date — YYYY-MM-DD
  • startAt / endAt — HH:mm, сетка 15 минут
  • projects — названия проектов через |
  • lifeArea — существующая Область жизни (для новых проектов)

API

Базовый префикс — /api/v1. Health-check: GET /actuator/health.

Как править эту доку без пересборки

  1. Редактируй файлы в папке docs-site/ в корне репозитория.
  2. Сохрани — контейнер wolf-docs отдаёт их напрямую через bind-mount.
  3. Обнови вкладку браузера (Ctrl+F5 при кэше). Пересборка Docker не нужна.

Новые страницы кладутся туда же: docs-site/guide.html → /docs/guide.html.
