# Тикет 04 — Заметки

Источник: `.scratch/release-0.2/issues/04-notes-crud.md`.

## TC-0.2-04-01 — Заметка к Проекту
**Приоритет:** Critical · **Тип:** UI

На странице Проекта создать markdown-Заметку с тегами `spring, security`, изменить её и удалить. Заметка, markdown и теги сохраняются; удаление работает.

## TC-0.2-04-02 — Заметка к Делу
**Приоритет:** Critical · **Тип:** UI

Создать Заметку на странице Дела. Она отображается в блоке этого Дела и не попадает в список другого Проекта.

## TC-0.2-04-03 — Ровно один владелец
**Приоритет:** High · **Тип:** API-only fallback

Отправить создание без `projectId` и `deloId`, затем с обоими. Оба запроса отклоняются с `400`, данные не создаются.

## TC-0.2-04-04 — Фильтры и поиск
**Приоритет:** Critical · **Тип:** UI

Создать заметки разных авторов и тегов, одна содержит «Spring Security». Фильтры по Проекту, Делу, автору и тегу ограничивают выдачу; поиск находит текст.

## TC-0.2-04-05 — Стиль agent
**Приоритет:** High · **Тип:** UI

Заметка с `author=agent` имеет отдельный стиль/иконку и отличается от заметки пользователя.

## TC-0.2-04-06 — Изоляция данных
**Приоритет:** High · **Тип:** UI

Другой пользователь не видит заметки чужих Проектов или Дел.
