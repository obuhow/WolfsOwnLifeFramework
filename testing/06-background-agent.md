# Тикет 06 — Фоновый агент

Источник: `.scratch/release-0.2/issues/06-background-agent.md`.

## TC-0.2-06-01 — Ручной запуск создаёт подложку
**Приоритет:** Critical · **Тип:** UI/API-only setup

Есть активный Проект и включён NotesAssistant. Выполнить ручной запуск через admin-инструмент или `POST /api/v1/admin/agent/run`, открыть Проект. Появляется Заметка автора `agent` с fake-результатом и тегом `agent-suggestion`; пользовательские Заметки не меняются.

## TC-0.2-06-02 — Неактивный Проект не обрабатывается
**Приоритет:** High · **Тип:** API-only setup

Проект без активности 14 дней и не в статусе «в работе» не получает агентскую Заметку.

## TC-0.2-06-03 — Идемпотентность запуска за сутки
**Приоритет:** Critical · **Тип:** UI/API-only setup

Выполнить запуск дважды за одни сутки. Второй запуск не создаёт дубль подложки для того же Проекта.

## TC-0.2-06-04 — Журнал запуска
**Приоритет:** High · **Тип:** API-only setup

В `agent_run_log` есть время старта/окончания, количество обработанных Проектов, созданных Заметок и ошибка при наличии.

## TC-0.2-06-05 — Нет уведомлений
**Приоритет:** Critical · **Тип:** UI

После запуска нет push/email, всплывающего давления, красных бейджей и напоминаний. Подложка находится в Проекте и Утреннем обходе.
