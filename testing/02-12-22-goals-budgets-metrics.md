## TC-0.2-02-01 — CRUD Целей
**Приоритет:** Critical · **Тип:** UI

Создать Цель с названием, приоритетом и описанием; открыть карточку; изменить данные; архивировать. Цель появляется в списке, изменения сохраняются, архивная не считается активной.

## TC-0.2-02-02 — Недельный бюджет
**Приоритет:** Critical · **Тип:** UI

Задать бюджет 10 ч на ISO-неделю, обновить страницу и изменить его на 7.5 ч. Значение сохраняется без штрафа или красного индикатора.

## TC-0.2-02-03 — Метрика и история
**Приоритет:** High · **Тип:** UI

Создать метрику «Вес» со значением 90; добавить 89.5 и 89 с разными датами. Текущее значение и история отображаются в правильном порядке.

## TC-0.2-02-04 — Приоритеты
**Приоритет:** High · **Тип:** UI

Создать две Цели, изменить порядок drag-and-drop и попробовать занять существующий приоритет. Порядок сохраняется, дубль отклоняется.

## TC-0.2-02-05 — Факт часов по Цели
**Приоритет:** Critical · **Тип:** UI/API-only setup

Связать Цель с Проектом и добавить 5 ч выполненных Записей в текущей ISO-неделе. Факт Цели равен 5 ч. Проверить также `primary_only` и `all_projects` для Дела с несколькими Проектами.

## TC-0.2-02-06 — Цель и Проект — разные сущности
**Приоритет:** High · **Тип:** UI

Цель отображается как верхнеуровневый вектор с бюджетом и метриками, Проект — как связанная инициатива; создание одного не создаёт автоматически другое.

# Тикет 12 — Статистика «волны продуктивности»

## TC-0.2-12-01 — Диапазон 4/12/26 недель
**Приоритет:** High · **Тип:** UI

Открыть `/stats`, переключить 4, 12 и 26 недель. График перестраивается, недели без факта показываются как 0.

## TC-0.2-12-02 — Агрегаты
**Приоритет:** High · **Тип:** UI

При разных значениях по неделям среднее, медиана, максимум и минимум соответствуют данным; оценок «хорошо/плохо» нет.

## TC-0.2-12-03 — Нейтральная визуализация
**Приоритет:** Critical · **Тип:** UI

Есть подпись о нормальности волнообразной продуктивности; отсутствуют красные зоны, стрики, «потерянные дни» и сравнение с идеалом.

# Тикет 22 — Быстрый инкремент метрик

## TC-0.2-22-01 — +1 и +5
**Приоритет:** High · **Тип:** UI

Для метрики current 3/target 500 нажать +1 и +5. Значения становятся 4 и 9; изменения попадают в историю.

## TC-0.2-22-02 — Произвольный инкремент
**Приоритет:** High · **Тип:** UI

Ввести +12. Значение увеличивается на 12, в истории появляется запись.

## TC-0.2-22-03 — Границы
**Приоритет:** Critical · **Тип:** UI

Попробовать уйти ниже 0 и превысить target. Операции отклонены, значение и история не меняются.

## TC-0.2-22-04 — Повторное нажатие
**Приоритет:** High · **Тип:** UI

Быстро нажать +1 дважды и обновить страницу. Каждое подтверждённое нажатие учтено ровно один раз.
