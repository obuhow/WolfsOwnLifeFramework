# Тикет 05 — NotesAssistant: аудио, транскрипт и resume

Источник: `.scratch/release-0.2/issues/05-notes-assistant-port.md`.

## TC-0.2-05-01 — Аудио превращается в Заметку с транскриптом
**Приоритет:** Critical · **Тип:** UI/API-only setup

**Предусловия:** включён LLM-флаг, настроен fake/test assistant; есть короткий аудиофайл и Проект.

**Шаги:** загрузить аудио в форме Заметки и выбрать Проект.

**Ожидаемый результат:** файл сохраняется, fake возвращает транскрипт, создаётся Заметка с этим текстом и ссылкой на аудио.

## TC-0.2-05-02 — Resume Проекта
**Приоритет:** Critical · **Тип:** UI

**Предусловия:** Проект содержит 3 Заметки с различимыми ключевыми словами.

**Шаги:** открыть «На чём я остановился?» и указать лимит `3`.

**Ожидаемый результат:** отображается сводка fake assistant, содержащая ключевые слова последних Заметок; старые заметки за пределами лимита не используются.

## TC-0.2-05-03 — Выключенный LLM
**Приоритет:** High · **Тип:** UI/API-only setup

**Предусловия:** `wolf.llm.enabled=false`.

**Шаги:** попробовать транскрипт и resume.

**Ожидаемый результат:** операции возвращают `503` с пояснением; приложение не создаёт пустую Заметку и не падает.

## TC-0.2-05-04 — Ошибка аудиофайла
**Приоритет:** Medium · **Тип:** UI

**Шаги:** загрузить пустой или неподдерживаемый файл.

**Ожидаемый результат:** отображается понятная ошибка валидации; частичной Заметки без транскрипта нет.
