# Тикет 09 — Честный прогноз Gantt

Источник: `.scratch/release-0.2/issues/09-gantt-forecast.md`.

## TC-0.2-09-01 — Прогноз по среднему
**Приоритет:** Critical · **Тип:** UI/API-only setup

Проект 60 ч, факт 5 ч за 4 ISO-недели, накоплено 20 ч. В Планировании remaining 40 ч, weeklyAvg 5 ч и прогноз примерно 8 недель; план и прогноз разделены.

## TC-0.2-09-02 — Clamp при перевыполнении
**Приоритет:** Critical · **Тип:** UI/API-only setup

При плане 40 ч и факте 45 ч остаток 0; прогноз не уходит в отрицательные недели.

## TC-0.2-09-03 — Нет факта
**Приоритет:** High · **Тип:** UI

Для проекта без факта показано «данных для прогноза пока мало»; нет «нулевого темпа» и красного состояния.

## TC-0.2-09-04 — Зависимый Проект
**Приоритет:** High · **Тип:** UI

При зависимости B от A прогноз старта B не раньше прогнозируемого финиша A.

## TC-0.2-09-05 — Месячная заморозка
**Приоритет:** Medium · **Тип:** UI/API-only setup

План фиксирован на месяц, прогноз обновляется от факта; разница видна без сигнала тревоги.

# Тикет 11 — Импорт и экспорт `wolf-data` v0.2

Источник: `.scratch/release-0.2/issues/11-xlsx-import.md`.

## TC-0.2-11-01 — Формат и шаблоны
**Приоритет:** High · **Тип:** UI/API-only fallback

Доступны manifest и шаблоны для Проектов, Рутин, Дел, Записей времени и связей; версия `wolf-data v0.2` указана.

## TC-0.2-11-02 — Preview валидного набора
**Приоритет:** Critical · **Тип:** UI

Загрузить CSV/XLSX с Проектом, Рутиной, Делом, Записью времени, externalId и связями. Preview показывает типы/количества, valid=true и ноль ошибок; данные не изменились.

## TC-0.2-11-03 — Ошибка и атомарность
**Приоритет:** Critical · **Тип:** UI

В строке указать неизвестный `lifeSphereId`. Ошибка содержит секцию/лист и номер строки; apply не создаёт сущностей и не оставляет частичных изменений.

## TC-0.2-11-04 — Apply и round-trip
**Приоритет:** Critical · **Тип:** UI/API-only setup

Применить валидный набор, экспортировать CSV/XLSX и применить в чистом профиле. ExternalId, поля, расписания, связи, статусы и интервалы восстановлены без потери и дублей.

## TC-0.2-11-05 — Повторный импорт
**Приоритет:** High · **Тип:** UI

Применить набор дважды. Повторный apply обновляет/пропускает сущности по externalId, но не создаёт дубли.

## TC-0.2-11-06 — Legacy XLSX flow
**Приоритет:** Critical · **Тип:** UI

Файл содержит известную, неизвестную и пустую ячейки. Известная создаёт выполненную Запись, неизвестная ставит импорт на паузу, пустая получает `unknown`; resolve продолжает импорт, повтор не создаёт дублей.

## TC-0.2-11-07 — Экспорт без секретов
**Приоритет:** Critical · **Тип:** UI

В файле отсутствуют JWT, пароли, секреты и внутренние технические идентификаторы; присутствуют только поддерживаемые данные и externalId.
