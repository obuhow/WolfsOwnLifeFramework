# Тикет 08 — Зависимости между Проектами

Источник: `.scratch/release-0.2/issues/08-project-dependencies.md`.

## TC-0.2-08-01 — A блокирует B
**Приоритет:** Critical · **Тип:** UI

На странице B добавить A как блокирующий Проект. На B A виден в «ждёт», на A B виден в «блокирует».

## TC-0.2-08-02 — Цикл A↔B
**Приоритет:** Critical · **Тип:** UI

При существующей связи A→B добавить B→A. Операция отклоняется с `409`, путь цикла понятен, исходная связь сохранена.

## TC-0.2-08-03 — Цикл в цепочке A→B→C→A
**Приоритет:** Critical · **Тип:** UI/API-only setup

Создать A→B и B→C, добавить C→A. Связь отклоняется с объяснением полного цикла.

## TC-0.2-08-04 — Удаление и повторное добавление
**Приоритет:** High · **Тип:** UI

Удалить зависимость и повторить допустимое добавление. Связь удаляется и создаётся заново без дублей.
