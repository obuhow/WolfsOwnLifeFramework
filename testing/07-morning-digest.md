# Тикет 07 — Утренний обход

Источник: `.scratch/release-0.2/issues/07-morning-digest.md`.

## TC-0.2-07-01 — Состав страницы «Утро»
**Приоритет:** Critical · **Тип:** UI

**Предусловия:** активный Проект с 5 Заметками и 3 Делами, 2 Идеи в банке, Цель с бюджетом и фактом.

**Шаги:** открыть `/morning`.

**Ожидаемый результат:** для каждого активного Проекта видны последние 5 Заметок, верхние 3 Дела, блок Идей и полоса факта/бюджета Цели.

## TC-0.2-07-02 — Заметки user и agent
**Приоритет:** High · **Тип:** UI

Пользовательские и агентские Заметки входят в дайджест, свежие отображаются сверху и визуально различаются.

## TC-0.2-07-03 — Идеи и переходы
**Приоритет:** Medium · **Тип:** UI

Нажать Проект и Идею в дайджесте. Открываются соответствующие карточки; Идеи выбираются из статуса «в банке» и по возможности представлены разными категориями.

## TC-0.2-07-04 — Нейтральная полоса Цели
**Приоритет:** Critical · **Тип:** UI

При факте Цели меньше бюджета показываются фактические часы и бюджет в нейтральном стиле. Нет красного индикатора, «недобора», «провала» или напоминания.
